# 线性方程组

> 解 Ax=b 是数学史上最老的问题之一，而它今天仍在替你训练神经网络。

**类型：** 构建
**语言：** Python
**先修知识：** 第1阶段，第01课（线性代数直觉）、第02课（向量与矩阵）、第03课（矩阵变换）
**时间：** 约120分钟

## 学习目标

- 用带部分主元的高斯消元 + 回代，亲手解出 Ax=b
- 做 LU、QR、Cholesky 三种分解，并说清各自什么时候值得用
- 把最小二乘的正规方程推出来，看清它就是线性回归和岭回归的闭式解
- 用条件数判断"这个答案还能不能信"，并用正则化把它救回来

## 问题

你每训练一次线性回归，就在解一个线性方程组。每次拟合最小二乘，还是在解。神经网络的 \(y=Wx+b\) 是方程组的一侧；加正则化是在改这个方程组；高斯过程要分解矩阵；马氏距离要算逆协方差——本质仍是解方程。

所以 \(Ax=b\) 无处不在：A 是已知的系数矩阵，b 是已知的结果，x 是你要找的未知量。

在线性回归里，A 是数据矩阵，b 是标签，x 是权重。整个模型被压成一句话：**找一个 x，让 Ax 尽量贴近 b。**

这一课从零把各种解法造一遍。你会看清为什么有的快、有的稳；为什么有的只认方阵、有的能处理"方程比未知数多"；以及为什么**条件数**决定了你算出来的答案是不是一堆浮点垃圾。

## 概念

### 先看图：Ax=b 到底在说什么

每个方程都是一张"超平面"。三维里是两个平面，二维里是两条直线。解，就是它们相交的那一点。

```text
2x + y = 5
x - y = 1

两条直线交于 x = 2, y = 1
```

只有三种结局，没有第四种：

- **一解**：交于一点，A 可逆。
- **无解**：两条平行线，永远不碰头，系统"不一致"。
- **无穷解**：两个方程其实是同一张平面，A 有零空间。

而机器学习里绝大多数情况，掉在"无精确解"这一格——**因为你的数据点（方程）永远比参数（未知数）多。** 这就是最小二乘登场的理由。

> 注：m>n 是常态，不是意外。你要用几千个样本去拟合十几个参数，方程组注定超定。既然精确解不存在，就只能退一步，找"最接近"的那个。

### 两种读法：行图与列图

同一个 \(Ax=b\)，可以横着读，也可以竖着读。

**横着读（行图）**：A 的每一行是一个方程、一张超平面，解是它们的交点。

**竖着读（列图）**：A 的每一列是一个向量。问题变成："**用 A 的这几列，各自配多少比例，才能混出 b？**"

```text
A = |2  1|     b = |5|
    |1 -1|         |1|

列图：找 x1, x2 使  x1*[2,1] + x2*[1,-1] = [5,1]

2*[2,1] + 1*[1,-1] = [5,1]   ✓
```

**列图才是更本质的那一版。** 想调配一杯饮料，A 的列是你手上的几种原料，x 是各倒多少，b 是你想要的味道。b 落在这些原料能调出的范围内（列空间），就能精确调配；调不出来，就找最接近的那杯——这恰好就是最小二乘解的几何意义。

### 高斯消元：一条一条把变量消掉

这就是你中学解三元一次方程的那个手写流程，只是换成了矩阵写法：**用行与行相减，把对角线下方一格一格清零，搞成上三角，然后从最后一个方程倒着解回来。**

```text
算法：
1. 对每一列 k（当前的主元列）：
   a. 在第 k 行及以下，找第 k 列绝对值最大的那个元素（部分主元）
   b. 把它所在的行和第 k 行交换
   c. 对 k 下方每一行 i：
      m = A[i][k] / A[k][k]        # 比例
      row_i = row_i - m * row_k    # 把这一列消成 0
2. 回代：从最后一个方程开始，往上逐个代
```

复杂度 \(O(n^3)\)。1000×1000 的矩阵大约十亿次浮点运算——在现代机器上是一瞬间，但如果你要对**同一个 A** 解 1000 个不同的 b，每次都从头消元就太蠢了。这正是 LU 要解决的问题。

### 部分主元：别拿小数字做除数

消元时你要除以主元。这一步藏着两个雷：

- 主元恰好是 0 → 除零，直接崩。
- 主元非常小 → 舍入误差被放大成千上万倍。

```text
坏主元（不换行）：              部分主元（先换行）：
|0.001  1 |  1.001 |           |1      1 |  2     |
|1      1 |  2     |           |0.001  1 |  1.001 |

m = 1/0.001 = 1000            m = 0.001/1 = 0.001
```

第一种里，乘子 m 高达 1000，意味着"第二行减 1000 倍第一行"。在浮点里，这一步会把第一行那点微小的舍入误差放大 1000 倍，塞进第二行，把本来有效的信息彻底淹没。

换行之后，乘子变成 0.001——**乘子总是 ≤ 1，误差只会被缩小，不会被放大。**

> 注：这就是数值稳定性的第一课：**除以小数等于用放大镜看误差。** 选最大的主元，等价于让所有乘子都小于 1，从而保证误差不被放大。

### LU 分解：拆一次，之后每次都便宜

LU 的思路是把消元过程"存下来"：

\[
A = LU
\]

L 是下三角，装的是消元时用到的那些乘子；U 是上三角，就是消元后的结果。等于说：**把"怎么消"和"消完的样子"各存一份。**

为什么值得存？因为分解完之后，每来一个新的 b，求解只要 \(O(n^2)\)：

```text
Ax = b  →  LUx = b  →  令 y = Ux：
  Ly = b   （前代，O(n²)，从上往下解）
  Ux = y   （回代，O(n²)，从下往上解）
```

那个 \(O(n^3)\) 的大头，只在分解时付一次。

所以如果你要拿同一个 A 解 1000 个 b（实际中常见：同一个协方差矩阵对应不同的右端项），LU 的总工作量只有反复消元的约 1/1000。**这不是小优化，这是数量级的差距。**

带部分主元的版本写成 \(PA=LU\)，P 是一个记录"哪几行交换过"的置换矩阵。

### QR 分解：把 A 的列扶正

QR 把 A 拆成一个正交矩阵 Q 和一个上三角 R：

\[
A = QR
\]

什么叫"正交矩阵"？\(Q^TQ=I\)，它的列是标准正交的——**互相垂直，长度都是 1**。用它去乘一个向量，长度和夹角都不变，只是换了个坐标系（像旋转了一下，不拉伸不压缩）。

```text
A = Q @ R
Q 的列标准正交：Q^T Q = I
R 上三角

求解 QRx = b：
  Rx = Q^T b    （两边左乘 Q^T，Q^TQ=I 直接消掉，不用求逆）
  然后回代
```

为什么不用求逆？因为正交矩阵的逆就是它的转置，白送。而且这一步数值极其稳。

**Gram-Schmidt 怎么把 Q 造出来**——一根一根把斜的柱子扶正：

```text
q1 = a1 / ||a1||                        # 第一根：归一化

q2 = a2 - (a2·q1) q1，再归一化            # 第二根：先减掉它在 q1 上的投影，剩下的才与 q1 垂直

q3 = a3 - (a3·q1) q1 - (a3·q2) q2，再归一化   # 第三根：把前两根的投影都减掉

R[i][j] = qi · aj   （i <= j）
```

每一步都是"把前面已经扶正的柱子方向上的分量减掉，只留全新的垂直方向"。这就是"正交化"三个字的字面意思。

QR 比 LU 更稳，尤其在解最小二乘时。代价是算得更慢一些，所以一般"能 LU 就 LU"，需要稳的时候才上 QR。

### Cholesky 分解：矩阵的平方根

如果 A 不只是方阵，还**对称**（\(A=A^T\)）且**正定**（所有特征值 > 0），那它可以拆成：

\[
A = LL^T
\]

L 是下三角。形式上，这就像是"A 的平方根"——顺手也能看出为什么要求正定：负数没有实数平方根。

```text
L[i][i] = sqrt(A[i][i] - Σ_{k<i} L[i][k]²)
L[i][j] = (A[i][j] - Σ_{k<j} L[i][k]L[j][k]) / L[j][j]     (i > j)
```

好处很直接：**比 LU 快一倍，存储省一半。**

为什么快一倍？因为对称，你只需要算半边表，另一半是抄的。为什么快一倍就够了不起了？因为这一步是 \(O(n^3)\)，减半就是实打实的 2 倍加速。

哪些矩阵天生对称正定？一大堆：

- **协方差矩阵**（半正定，加一点正则化就严格正定）
- **高斯过程的核矩阵**
- **凸函数极小值处的 Hessian**
- **\(A^TA\)**，永远是半正定——所以最小二乘的正规方程天然适合 Cholesky

高斯过程里的用法最典型：分解核矩阵 \(K=LL^T\)，然后解 \(K\alpha=y\) 得预测均值；对数边际似然里的 \(\log\det(K)\) 也白送：\(\log\det(K)=2\sum_i\log L_{ii}\)，连行列式都不用单独算。

> 注：Cholesky 是"专精版"的 LU。它不讲通用性，只吃对称正定这一种结构，但正因为吃得专，所以又快又省又稳。碰到协方差矩阵、核矩阵，默认就该想到它。

### 最小二乘：没有精确解，就找最近的那个

A 是 m×n 且 m>n（方程比未知数多），精确解不存在。那就换个目标：**让残差最小。**

\[
\min_x \|Ax-b\|^2 = \sum_i \left(a_i^Tx - b_i\right)^2
\]

这里有个漂亮的几何图像：b 不在 A 的列空间里，我们就把它**垂直投影**到列空间上，投影点就是最接近的可达点，对应的 x 就是最小二乘解。垂足之所以是最短距离，因为"垂直"就是"再也没法靠近"。

对 x 求梯度置零，就得到**正规方程**：

\[
A^TAx = A^Tb
\]

推导只要三步：展开 \(\|Ax-b\|^2 = x^TA^TAx - 2x^TA^Tb + b^Tb\)，对 x 求梯度得 \(2A^TAx - 2A^Tb\)，置零。

```text
超定系统（4 个方程、2 个未知数）：
|1 1|        |3|
|1 2|  x  =  |5|      无精确解
|1 3|        |6|
|1 4|        |8|

正规方程：
  A^T A = | 4  10 |      A^T b = | 22 |
          |10  30 |              | 63 |

解出 x = [1.5, 1.6]  → 截距 1.5、斜率 1.6

回验：四点预测 3.1 / 4.7 / 6.3 / 7.9，和 3 / 5 / 6 / 8 最接近
```

### 正规方程就是线性回归

这不是类比，是同一件事。

线性回归里，数据矩阵 X 每行一个样本、每列一个特征，标签 y，权重 w。最优的 w 满足：

\[
X^TXw = X^Ty \quad\Longrightarrow\quad w = (X^TX)^{-1}X^Ty
\]

这就是线性回归的**闭式解**。你每次调 `LinearRegression.fit()`，底层算的就是它（或者用 QR/SVD 算等价的东西）。

加上 \(L2\) 正则项以后，变成**岭回归**：

\[
(X^TX+\lambda I)w = X^Ty
\]

加 \(\lambda I\) 有两个作用，一个数学的、一个统计的：

- **数学上**：让矩阵更好条件，更容易准确求逆。
- **统计上**：把权重往零的方向收缩，抑制过拟合。

而且只要 \(\lambda>0\)，\(X^TX+\lambda I\) 就必然对称正定——于是可以直接上 Cholesky。这也是岭回归在实践中特别好解的原因。

> 注：正规方程有个隐蔽的代价：\(\mathrm{cond}(X^TX)=\mathrm{cond}(X)^2\)。**条件数是平方关系**，X 稍有点病态，X^TX 就病得离谱。所以大问题上更常用 QR 或 SVD，或者干脆梯度下降。

### 伪逆：给"不能求逆"的矩阵一个说法

方阵、可逆，才有逆。但现实里矩阵经常是长方形（超定或欠定），或者干脆奇异。伪逆 \(A^+\)（Moore-Penrose）把求逆推广到这些情况：

\[
x = A^+b,\qquad A^+ = V\Sigma^+U^T
\]

做法是先 SVD：\(A=U\Sigma V^T\)，然后把 \(\Sigma\) 里的每个**非零**奇异值取倒数、转置，零保持零。

这个"零保持零"很关键：**不去除以零，就等于把那些无法确定的方向直接跳过。**

伪逆给出的是"最小范数最小二乘解"，一句话涵盖三种情况：

- **有唯一解**：就是那个解。
- **无解（超定）**：给出残差最小的那个。
- **无穷多解（欠定）**：给出其中长度最短的那个——即"能解释数据的最小改动"。

NumPy 的 `lstsq` 和 `pinv` 内部都是 SVD。

### 条件数：这个答案还剩几位可信？

条件数回答一个问题：**输入动一点点，输出会动多少？**

\[
\kappa(A) = \|A\|\,\|A^{-1}\| = \frac{\sigma_{\max}}{\sigma_{\min}}
\]

就是最大奇异值除以最小奇异值。

```text
良态（κ ≈ 1）：b 微动 → x 微动
病态（κ ≈ 10^15）：b 微动 → x 剧烈乱跳

|2 0|  κ = 2/1 = 2，安全          |1    1    |  κ ≈ 10^15，解出来是垃圾
|0 1|                            |1  1+1e-15 |
```

经验法则：

- \(\kappa < 100\)：安全，解基本准确。
- \(\kappa \sim 10^k\)：大约损失 k 位有效数字。
- \(\kappa \sim 10^{16}\)：float64 已经没救了，矩阵实际上就是奇异的。

ML 里的病态几乎总来自一个原因：**特征之间高度共线。** 两列几乎一模一样，矩阵就接近不可逆。物理直觉很清楚：如果两个特征提供的是同一份信息，那么"到底该把权重分给谁"这个问题根本没有唯一答案，数值上就表现为解在巨大范围内乱飘。

正则化是一剂解药：条件数从 \(\sigma_{\max}/\sigma_{\min}\) 变成 \((\sigma_{\max}+\lambda)/(\sigma_{\min}+\lambda)\)。分子分母同时加一个正数，比值立刻被压到温和的范围。

> 注：把条件数想成"误差放大器"。\(\kappa=10^k\) 意味着输入的 \(10^{-k}\) 相对误差，会被放大到 \(O(1)\) 的量级。所以病态系统里，**算法再正确也没用——浮点噪声本身就会把答案淹没。**

### 共轭梯度：大到没法分解时，就迭代着逼近

如果系统有上百万个未知数，还极其稀疏（大部分元素是 0），LU 和 Cholesky 的 \(O(n^3)\) 直接劝退。这时改用迭代法：从一个瞎猜的初值出发，每一轮往正确答案挪一点。

共轭梯度（CG）要求 A 对称正定。理论上最多 n 步精确收敛，但实际上特征值聚得越紧，收敛越快（几十步就够）。

```text
x0 = 初始猜测（一般取 0）
r0 = b - A x0            # 残差：现在还差多少
p0 = r0                  # 搜索方向

每一步 k：
  alpha = (r_k·r_k) / (p_k·A p_k)
  x_{k+1} = x_k + alpha p_k
  r_{k+1} = r_k - alpha A p_k
  beta = (r_{k+1}·r_{k+1}) / (r_k·r_k)
  p_{k+1} = r_{k+1} + beta p_k
  若 ||r_{k+1}|| < tol 就停
```

"共轭"这个词的意思是：每一步挑的方向，都相对之前走过的方向"互不干扰"，所以不会走回头路、不会来回打转。这是它比最陡下降快得多的根本原因。

用在哪：大规模优化（Newton-CG）、偏微分方程离散、核矩阵太大分解不动、以及给别的迭代求解器当预条件子。

收敛速度取决于条件数——**病态系统里 CG 也会磨蹭。** 这又回到那句老话：正则化能让条件数变好，等于让所有求解方法都变快。

### 全景：什么时候用哪一招

| 方法 | 前提 | 成本 | 用在哪 |
|------|------|------|------|
| 高斯消元 | 方阵、可逆 | O(n³) | 一次性解个方阵 |
| LU | 方阵、可逆 | 分解 O(n³) + 每次求解 O(n²) | 同一个 A 反复解 |
| QR | 任意 A（m≥n） | O(mn²) | 最小二乘、要数值稳定时 |
| Cholesky | 对称正定 | O(n³/3) | 协方差、GP、岭回归 |
| 正规方程 | 超定（m>n） | O(mn² + n³) | 线性回归（n 不大时） |
| SVD/伪逆 | 任意 A | O(mn²) | 秩亏系统、要最小范数解 |
| 共轭梯度 | 对称正定、稀疏 | O(n·k·nnz) | 超大稀疏系统 |

### 这些方法在生产里都在哪

- **线性回归**：解 \(X^TXw=X^Ty\)，小 n 用 Cholesky，要稳用 QR，怕秩亏用 SVD。
- **岭回归**：加 \(\lambda I\) 后恒为对称正定，Cholesky 直接上。
- **高斯过程**：预测均值解 \(K\alpha=y\)，Cholesky 分解 K，对数边际似然直接用 \(\log\det K\)。
- **正交初始化**：用 QR 造出一组标准正交的权重列，防止深层网络信号逐层塌缩。
- **预条件子**：大规模优化里用不完全 Cholesky/LU 给 CG 加速。
- **特征工程**：算出 \(X^TX\) 的条件数，就知道特征是不是共线；\(\kappa\) 太大，要么删特征，要么加正则。

## 练习

1. 用自己写的消元求解器、LU 求解器、`np.linalg.solve` 分别解 `[[1,2,3],[4,5,6],[7,8,10]] x = [6,15,27]`，验证三者在浮点容差内一致。
2. 造一个 50×5 的随机 X 和 \(y=Xw+\text{噪声}\)，分别用正规方程、QR、SVD、`lstsq` 求 w 并比较；算出 \(X^TX\) 的条件数，解释它如何影响你该信任哪种方法。
3. 让第 2 列等于第 1 列加 \(10^{-10}\) 的噪声，人为制造近奇异矩阵，算条件数；然后分别在有正则化（加 \(0.01I\)）和无正则化下求解，比较解和残差，解释正则化为什么有用。
4. 给一个 100×100 的随机对称正定矩阵实现共轭梯度，数一下收敛到 1e-8 用了多少步，和理论上限 n 比较。
5. 在 10 / 50 / 200 / 500 四种规模的对称正定矩阵上计时 Cholesky、LU、`np.linalg.solve`，画图验证 Cholesky 大约比 LU 快 2 倍。

| 术语 | 人们常说 | 实际含义 |
|------|---------|---------|
| 线性方程组 | "解 x" | Ax=b，求 x 就是找那个"经 A 变换后得到 b"的输入 |
| 高斯消元 | "行化简" | 用行相减把对角线下方清零，得三角系统再回代，O(n³) |
| 部分主元 | "换行保稳定" | 消元前把该列绝对值最大的行换上来，避免拿小数做除数 |
| LU 分解 | "拆成两个三角" | A=LU，L 存乘子、U 是消元结果，把 O(n³) 摊到多次求解 |
| QR 分解 | "正交分解" | A=QR，Q 列标准正交，最小二乘比 LU 更稳 |
| Cholesky 分解 | "矩阵的平方根" | 对称正定 A=LLᵀ，成本约为 LU 的一半，协方差/核/岭回归全用它 |
| 最小二乘 | "算不出精确解时最好的那个" | 超定系统里最小化残差平方和 ‖Ax-b‖² |
| 正规方程 | "一道求导捷径" | AᵀAx=Aᵀb，把 ‖Ax-b‖² 的梯度置零，就是线性回归闭式解 |
| 伪逆 | "非方阵的求逆" | A⁺=VΣ⁺Uᵀ，对任意矩阵给出最小范数最小二乘解 |
| 条件数 | "答案还能信几位" | κ=σ_max/σ_min，衡量对扰动的敏感度，大约损失 log₁₀κ 位精度 |
| 岭回归 | "带正则的最小二乘" | 解 (XᵀX+λI)w=Xᵀy，改善条件数的同时把权重收缩向零 |
| 共轭梯度 | "大矩阵的迭代解法" | 对称正定系统的迭代求解器，最多 n 步收敛，适合大稀疏问题 |
| 超定系统 | "数据比参数多" | m>n，无精确解，只能最小二乘近似——几乎每个回归都是这样 |
| 回代 | "从下往上解" | 上三角系统从最后一个方程往上代入，O(n²) |
| 前代 | "从上往下解" | 下三角系统从第一个方程往下代入，O(n²)，LU 求解的第一步 |
