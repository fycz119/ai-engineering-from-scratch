# AI 中的复数

> -1 的平方根不"虚"。它是旋转、振荡，以及半个信号处理领域的母语。

**类型：** 学习
**语言：** Python
**先修知识：** 第1阶段，第01-04课（线性代数、微积分）
**时间：** 约60分钟

## 学习目标

- 在直角坐标和极坐标两种形式下熟练做复数的加、乘、除、共轭
- 用欧拉公式在"复指数"和"三角函数"之间自由切换
- 用单位根亲手拼出 DFT
- 解释复数旋转如何支撑 Transformer 的 RoPE 和正弦位置编码

## 问题

你翻开一篇讲傅里叶变换的论文，满屏都是 \(i\)。Transformer 的位置编码里塞着一堆频率不同的 sin/cos——它们其实是复指数的实部和虚部。量子计算干脆整个建立在复向量空间上。

复数看起来抽象，像是搭在 \(\sqrt{-1}\) 上的数学游戏。但**它真不是游戏，它是描述"转圈"和"振动"的天然语言。** 只要一个东西在旋转、在震荡、在周期性重复，复数就是最顺手的工具。

不懂复数，你就看不懂 DFT、FFT，看不懂现代 LLM 里的 RoPE，也看不懂原版 Transformer 为什么偏偏挑那些频率做正弦位置编码。

这一课从零把复数运算建起来，接到几何上，最后指出它在 ML 里到底藏在哪。

## 概念

### 复数：一根平面上的箭头

复数由两部分组成：

\[
z = a + bi
\]

\(a\) 是实部，\(b\) 是虚部，\(i\) 是虚数单位，满足 \(i^2=-1\)。

**真正的转折点在这里：把数轴换成平面。** 横轴放实数，纵轴放虚数，于是每个复数都对应平面上的一个点——同时也是**从原点指向这个点的一根箭头**。

这个"既是点、又是箭头"的双重身份，是复数能用来说几何的根本原因。

### 复平面：横轴实数，纵轴虚数

这张平面就是复数的全部舞台：

```text
3 + 2i  ↔  (3, 2)
-1 + 0i ↔  (-1, 0)
0 + 4i  ↔  (0, 4)
```

**每个复数同时是"一个点"和"一根从原点指向它的向量"。** 正因为这层双重身份，复数的加法可以读成"向量首尾相接"，乘法可以读成"旋转加缩放"——几何和代数在这里是同一件事的两种写法。

### 四则运算：会乘法就够了一半

**加法**：实部加实部，虚部加虚部——就是箭头首尾相接。

\[
(a+bi)+(c+di)=(a+c)+(b+d)i
\]

**乘法**：按分配律展开，遇到 \(i^2\) 就换成 \(-1\)。

\[
(a+bi)(c+di)=ac+adi+bci+bdi^2=(ac-bd)+(ad+bc)i
\]

举例：\((3+2i)(1+4i)=3+12i+2i+8i^2=3+14i-8=-5+14i\)。

**共轭**：虚部变个号，也就是沿实轴照个镜子。

\[
\overline{a+bi}=a-bi,\qquad z\cdot\overline{z}=a^2+b^2
\]

最后那个乘积**一定是实数**——因为 \((a+bi)(a-bi)=a^2-i^2b^2=a^2+b^2\)。这条性质后面会反复用到。

**除法**：分子分母同乘分母的共轭，把分母变成实数。

\[
\frac{a+bi}{c+di}=\frac{(a+bi)(c-di)}{c^2+d^2}
\]

> 注：复数乘法最要紧的一点是——**它不是"坐标各自相乘"，而是"旋转 + 缩放"**。实数乘法只能拉伸或压缩，复数乘法还会顺手把你转一个角度。这是它和实数体系的根本区别，也是它在几何里好用的原因。

### 极坐标：一根箭头的"长度 + 朝向"

既然复数是箭头，那它就可以用两个更直观的量描述：多长、朝哪儿。

\[
z=r(\cos\theta+i\sin\theta),\qquad r=|z|=\sqrt{a^2+b^2},\quad \theta=\operatorname{atan2}(b,a)
\]

\(r\) 叫模（幅度），是从原点到点的距离；\(\theta\) 叫相位（幅角），是与正实轴的夹角。

**什么时候用哪种形式？这是本课最实用的一条经验：**

- **直角坐标（a+bi）适合加法**——直接分量相加。
- **极坐标（r, θ）适合乘法**——长度相乘、角度相加。

\[
z_1z_2=(r_1r_2)\,e^{i(\theta_1+\theta_2)}
\]

### 欧拉公式：把"转圈"写成一个指数

这座桥把指数和三角函数接了起来：

\[
e^{i\theta}=\cos\theta+i\sin\theta
\]

这是全课最重要的一行。取 \(\theta=\pi\)：

\[
e^{i\pi}=\cos\pi+i\sin\pi=-1
\]

于是 \(e^{i\pi}+1=0\)——五个最基本的常数（e、i、π、1、0）挤进了一个等式里。这个"最美公式"的称号不是白给的。

**它为什么在 ML 里重要？** 因为 \(e^{i\theta}\) 随 \(\theta\) 增大，正好**在单位圆上匀速跑圈**：

- θ=0 → (1, 0)
- θ=π/2 → (0, 1)
- θ=π → (-1, 0)
- θ=3π/2 → (0, -1)
- θ=2π → 回到 (1, 0)，跑完一圈

所以 **复指数 = 旋转**。而旋转这件事，在信号处理和 ML 里到处都是。

### 复数乘法 = 二维旋转矩阵

把点 \((x,y)\) 乘上 \(e^{i\theta}\)，它就会绕原点转 θ：

```text
复数算法：
  (x+yi)(cosθ + i sinθ) = (x cosθ - y sinθ) + (x sinθ + y cosθ)i

矩阵算法：
  [cosθ  -sinθ] [x]   [x cosθ - y sinθ]
  [sinθ   cosθ] [y] = [x sinθ + y cosθ]

结果一模一样。
```

**旋转矩阵只是复数乘法的矩阵写法。** 反过来看更直观：矩阵要存 4 个数，复数只要存 1 个角度。所以在纯二维旋转的场景里，用复数更省、更简洁。

### 相量：用"匀速转圈的箭头"代替"来回摆动的波"

\(e^{i\omega t}\) 是一个以角频率 ω 在单位圆上匀速转动的点。它的**实部是 cos(ωt)，虚部是 sin(ωt)**——正弦波只是这个旋转箭头的"影子"。

\[
e^{i\omega t}=\cos(\omega t)+i\sin(\omega t)
\]

这个表示法叫**相量**。好处极其实在：

- 正弦波摆来摆去，看得人眼花；旋转箭头是匀速平滑的，好处理。
- **相位偏移** → 变成角度偏移。
- **幅度变化** → 变成模长变化。
- **两个信号相加** → 变成两个箭头相加。

用三角函数做这些事，你得背一堆和差化积公式；用复指数，就是普通的复数加法和乘法。

### 单位根：把单位圆切成 N 等份

N 次单位根，就是单位圆上均匀分布的 N 个点：

\[
\omega_k=e^{2\pi ik/N},\qquad k=0,\dots,N-1
\]

- **N=4**：1, i, -1, -i —— 正好是罗盘上的四个正方向。
- **N=8**：四个正方向，再加四个对角线方向。

它们是 DFT 的地基，因为 DFT 就是拿这 N 个"等间距的频率"去拆解信号。

### DFT：拿 N 个转速不同的音叉去测信号

一段长度为 N 的信号 \(x[0..N-1]\)，它的 DFT 是：

\[
X[k]=\sum_{n=0}^{N-1}x[n]\,e^{-2\pi ikn/N}
\]

看不懂没关系，换个画面：

> 你手上有一段噪声波形。面前摆着 N 个音叉，第 k 个音叉的固有频率是"每 N 步转 k 圈"。你拿每个音叉去和信号"对一对"，**共振得越强，说明信号里这个频率的成分越多。** 每个音叉返回一个复数：模长 = 这个频率有多强，角度 = 这个成分的相位。

所以 DFT 干的事，就是把一段信号拆成 N 个旋转的相量，然后告诉你每一个的强度和起始角度。

### 为什么 i 一点也不"虚"

"imaginary number"这个名字是历史事故——笛卡尔当年带着轻蔑这么叫的。但 \(i\) 一点也不比负数更虚幻：负数刚被引入时也被当成异端，可它老老实实回答了"3 减 5 得什么"。

\(i\) 回答的是另一个同样正当的问题："**什么的平方等于 -1？**"

更有用的回答是：**\(i\) 就是一个"逆时针转 90°"的操作符。**

- 实数乘一次 i：从实轴转到虚轴，转了 90°。
- 再乘一次 i：又转 90°，总共 180°，指向负实轴。

**所以 \(i^2=-1\) 一点也不神秘——两次四分之一圈，合起来就是半圈。** 这才是它最该被记住的含义。

也正因为如此，凡是涉及旋转的东西——电磁波、量子态、信号振荡、位置编码——自然都用复数写。

### 复指数 vs 三角函数：工程师为什么集体搬家

欧拉公式之前，信号都写成 \(A\cos(\omega t+\varphi)\)。两个信号相加要用三角恒等式，相位一多就变成噩梦。

换成复指数 \(Ae^{i(\omega t+\varphi)}\) 之后：

- 相加 = 复数相加
- 相乘（调制）= 模长相乘、角度相加
- 相位偏移 = 角度加法

整个信号处理领域因此集体搬到复指数表示上，纯属为了少受罪。

**注意"真实信号"始终只是复表示的实部**——虚部并不存在，它只是记账用的辅助量，让代数运算能自然闭合。这个心理解释能解决很多人的困惑："为什么算出来的东西有一部分是虚的？"因为它本来就不该出现在最终答案里。

### 和 Transformer 的联系

**正弦位置编码（原版 Transformer）：**

```text
PE(pos, 2i)   = sin(pos / 10000^{2i/d})
PE(pos, 2i+1) = cos(pos / 10000^{2i/d})
```

每一对 sin/cos，其实就是一个特定频率的复指数的实部和虚部。

直观画面是**一排转速不同的钟表指针**：低频指针转得慢，能分辨"大尺度"的位置差（粗粒度）；高频指针转得快，能分辨"精细"的位置差（细粒度）。把它们全摆在一起，每个位置就获得了一个独一无二的"频率指纹"。

**RoPE（旋转位置嵌入）** 更进一步：它不只是"加"一个位置编码，而是把 query 和 key 向量**真的乘上一个复旋转矩阵**。

于是两个 token 的相对位置，就变成了它们之间的**旋转夹角**。注意力算内积时，旋转角一相减，绝对位置就消失了，只剩下"你比我早几步"这个相对信息——这正是 RoPE 想达到的效果，而复数乘法恰好是最自然的实现方式。

## 练习

1. **手算。** 算出 \((2+3i)(4-i)\) 并用代码验证；再算 \((5+2i)/(1-3i)\)。把结果画在复平面上，确认乘法确实对第一个数做了"旋转 + 缩放"。
2. **转圈。** 从 (1,0) 出发，连续乘 \(e^{i\pi/6}\) 十二次，验证最后回到 (1,0)。打印每一步坐标，确认轨迹构成一个正十二边形。
3. **已知信号的 DFT。** 采样 32 个点，信号为 \(\sin(2\pi\cdot 3t)+0.5\sin(2\pi\cdot 7t)\)，跑 DFT，验证幅度谱在频率 3 和 7 处出现峰，且 7 的峰高恰好是 3 的一半。
4. **单位根。** 算 8 次单位根，验证它们加起来等于 0；再验证任意一个单位根乘上本原根 \(e^{2\pi i/8}\) 就得到下一个。
5. **两种写法等价。** 随机取 10 个角度、10 个点，比较"复数乘法"与"2×2 旋转矩阵乘向量"的结果，打印最大数值差。

## 关键术语

| 术语 | 含义 |
|------|------|
| 复数 | a+bi，a 是实部，b 是虚部，i² = -1 |
| 虚数单位 | i，满足 i²=-1；它不"虚"，它就是一个 90° 旋转算子 |
| 复平面 | 横轴放实部、纵轴放虚部的二维平面（Argand 平面） |
| 模（幅度） | 到原点的距离 √(a²+b²)，记作 \|z\| |
| 相位（幅角） | 与正实轴的夹角 atan2(b,a)，记作 arg(z) |
| 共轭 | 沿实轴照镜子：a+bi 的共轭是 a-bi |
| 极坐标形式 | z = r e^{iθ}，让乘法变成"长度相乘、角度相加" |
| 欧拉公式 | e^{iθ} = cosθ + i sinθ，连接指数与三角 |
| 相量 | 用旋转复数 e^{iωt} 表示正弦信号 |
| 单位根 | ω_k = e^{2πik/N}，单位圆上的 N 个等分点 |
| DFT | 离散傅里叶变换，用单位根把信号拆成复正弦分量 |
| RoPE | 旋转位置嵌入，用复数乘法在注意力里编码相对位置 |
