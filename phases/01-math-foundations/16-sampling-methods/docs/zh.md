# 采样方法

> 采样是 AI"探索可能性"的唯一手段——它决定模型是死板还是疯癫。

**类型：** 构建
**语言：** Python
**先修知识：** 第1阶段，第06-07课（概率、贝叶斯定理）
**时间：** 约120分钟

## 学习目标

- 只靠均匀随机数，从零造出逆 CDF、拒绝采样、重要性采样三种方法
- 为语言模型搭出温度、top-k、top-p（核）采样，并说清它们各自在改什么
- 讲明白重参数化技巧为什么能让 VAE 里的采样也能反向传播
- 跑通 Metropolis-Hastings，从"只知道形状、不知道归一化常数"的分布里抽样本

## 问题

语言模型读完了你的 prompt，吐出 50,000 个 logits——词表里每个 token 一个分数。现在它得挑一个。

**永远挑分数最高的**：每次回答一字不差，像个复读机。
**完全随机挑**：输出是乱码，连语法都不成立。

正确答案在两端之间，而"落在哪"这件事，就是采样控制的。

而且采样远不止文本生成：强化学习靠采样轨迹估梯度；VAE 靠从学到的分布里采样、再把随机性反传回去；扩散模型靠采样噪声、一步步去噪出图；蒙特卡洛拿样本平均顶替算不出来的积分；MCMC 去探索压根没法枚举的高维后验。

**每个生成式模型本质上都是一台采样机。** 采样策略直接决定输出好不好、有没有变化、能不能控制。这一课从最原始的均匀随机数出发，一路造到现代 LLM 用的那套。

## 概念

### 为什么采样这么重要

采样在 AI 里干四件完全不同的事：

**造东西。** 语言模型、扩散模型、GAN，输出都是"采"出来的。温度、top-k、核采样，就是工程师每天在拧的那几个旋钮。

**训练。** SGD 采样小批量；Dropout 采样要关掉哪些神经元；数据增强采样随机变换；重要性采样在 PPO/TRPO 里给样本重新加权，压住梯度方差。

**估计。** 很多量没有闭式解：数据分布上的期望损失、能量模型的配分函数、贝叶斯证据。全都靠样本平均来近似。

**探索。** MCMC 逛后验；进化策略采样参数扰动；Thompson 采样在 bandit 里平衡"试试新的"和"用用好的"。

所有麻烦都源自一个事实：**你手上只有两种"原生"随机源——均匀和正态。** 想要别的形状，就得自己动手做转换。

### 均匀随机采样：唯一的原料

均匀随机数生成器吐出 [0,1) 之间的值，长度相等的区间概率相等。

```text
U ~ Uniform(0, 1)

P(a <= U <= b) = b - a      0 <= a <= b <= 1

性质：
  E[U] = 0.5
  Var(U) = 1/12
```

想从 n 个离散项里等概率挑一个：生成 U，取 `floor(n*U)`。想从区间 [a,b] 里均匀取：`a + (b-a)*U`。

**关键洞察**：一个均匀随机数携带的"随机量"刚好够造出任意分布的一个样本——前提是你找对了那个变换。

### 逆 CDF：把人排成一队，按分位点取人

先记住一个画面：

> 把全城的人按身高从矮到高排成一队。你闭着眼随机报一个位置，比如"从队头数第 30% 的位置"，然后把那儿的人的身高记下来。重复无数次，你就得到了这座城市的"身高分布样本"。

**这个动作就是逆 CDF 采样。** 你随机报的那个位置服从均匀分布，但映射出来的身高，自动服从人群的真实分布。高个子那边人少，队尾自然稀疏，采到的就少。

数学上只需要两步：

```text
CDF（累积分布函数）：F(x) = P(X <= x)
  - 单调不减
  - F(-inf) = 0，F(+inf) = 1
  - 把整条实数轴压到 [0, 1]

逆 CDF：给一个概率 u，返回"累计概率刚好到 u"的那个 x

算法：
  1. 生成 u ~ Uniform(0, 1)
  2. 返回 F^{-1}(u)

为什么对：
  P(X <= x) = P(F^{-1}(U) <= x) = P(U <= F(x)) = F(x)
```

等式最后一步之所以成立，是因为 F 单调不减，不等式可以直接"翻译"进概率里。

**指数分布为例**（比如"下一次请求还要等多久"）：

```text
PDF：f(x) = lambda * exp(-lambda * x),  x >= 0
CDF：F(x) = 1 - exp(-lambda * x)

解 F(x) = u：
  u = 1 - exp(-lambda * x)
  exp(-lambda * x) = 1 - u
  x = -ln(1 - u) / lambda

又因为 (1 - U) 和 U 同分布，可以简化成：
  x = -ln(u) / lambda
```

能写出闭式逆函数时就完美。正态分布的逆 CDF 没有闭式解，所以得换别的招（Box-Muller 或数值近似）。

**离散版**：把 CDF 换成前缀和，生成 U，找第一个"前缀和超过 U"的下标——这就是第 06 课的 `sample_categorical`。

> 注：逆 CDF 的本质叫"概率积分变换"。它是概率论里最漂亮的一条对称：任何分布的 CDF 作用在自己的随机变量上，都会得到均匀分布；反过来，均匀分布经逆 CDF 作用，就能变成任何分布。所以均匀分布是所有分布的"共同母语"。

### 拒绝采样：在方框里撒豆子，只收圆里的

逆 CDF 写不出来，但目标密度 \(p(x)\) 的**形状**你能算（哪怕差一个归一化常数），就用这一招。

想象你要在纸上画一个奇怪形状的区域，然后往里撒豆子——但你只会"均匀地往一个矩形里撒"。那就先拿一个**能把目标形状完全罩住**的矩形（或任意好采样的包络），撒豆子，落在目标形状内的收下，落在外面的一概扔掉。

```text
目标分布 p(x)（能算值，可能没归一化）
提案分布 q(x)（能采样）
包络常数 M，要求 p(x) <= M * q(x) 对所有 x 成立

算法：
  1. 采样 x ~ q(x)
  2. 采样 u ~ Uniform(0, 1)
  3. 若 u < p(x) / (M * q(x))，接受 x
  4. 否则扔掉，回到第 1 步

接受率 = 1/M
```

\(M\) 越贴边，浪费越少。一维到三维都很好用；**维度一高就废**——因为包络比目标"胖"出来的那部分体积随维度指数级膨胀，绝大多数豆子都白撒。这就是拒绝采样版的维度诅咒。

两个经典例子：

- **截断正态**：在截断区间上均匀提案，M 取该区间内正态密度的最大值。
- **半圆算 π**：在正方形里均匀撒点，落在半圆内的比例就是面积比 π/4，π ≈ 4 × 圆内点数 / 总点数。

> 注：拒绝采样是"精确"的——保留下来的样本严格服从目标分布，一点近似都没有。代价是效率，高维下几乎不可用。这正是 MCMC 存在的理由。

### 重要性采样：拿隔壁班的名单，估自己班的均值

有时候你根本不想要 \(p(x)\) 的样本，你只想算 \(p(x)\) 下的期望。而你手上只有从 \(q(x)\) 采来的样本。

像是：你想知道 A 校学生的平均身高，但你只有 B 校的名单。怎么办？**给每个 B 校学生加一个权重，权重 = "这个身高在 A 校出现的密度 / 在 B 校出现的密度"。** 在 B 校常见但在 A 校罕见的身高，权重就小；反之权重就大。加权平均一下，就近似出了 A 校的均值。

```text
目标：E_p[f(x)] = ∫ f(x) p(x) dx

改写：
  E_p[f(x)] = ∫ f(x) * (p(x)/q(x)) * q(x) dx
            = E_q[f(x) * w(x)]

其中 w(x) = p(x) / q(x) 叫重要性权重

估计：
  E_p[f(x)] ≈ (1/N) Σ f(x_i) w(x_i)，  x_i ~ q(x)
```

这在 RL 里是命根子。PPO 用旧策略 \(\pi_{old}\) 收集轨迹，却要优化新策略 \(\pi_{new}\)，两者之间的换算全靠重要性权重 \(\pi_{new}(a|s)/\pi_{old}(a|s)\)。PPO 那个著名的 clip 操作，就是为了防止新策略跑太远、把权重撑爆。

**坑在方差。** 估计好坏取决于 q 和 p 有多像。两者差得远，就会出现"少数几个样本权重巨大、其余几乎为零"的局面，估计器方差爆炸。缓解办法是自归一化：

```text
E_p[f(x)] ≈ Σ w_i f(x_i) / Σ w_i
```

除以权重总和，把绝对尺度消掉。

### 蒙特卡洛：用"数点"代替"算积分"

绝大多数积分算不出来，但你可以**撒点然后取平均**。

```text
目标：I = ∫_D g(x) dx

方法：
  1. 在 D 里均匀采样 x_1..x_N
  2. I ≈ (Vol(D)/N) Σ g(x_i)

误差：O(1/√N)，与维度无关
```

最后那句"与维度无关"是它封神的原因。

设想 10 维空间，每维切 100 格做网格积分：需要 \(100^{10}=10^{20}\) 个点，宇宙寿命都不够。蒙特卡洛只要 \(10^4\) 个随机点，误差还是 \(1/\sqrt{N}\)。**随机撒点打败了认真切格子**，因为它的误差只跟点数有关，不跟维度有关。

两种最朴素用法：

- **算 π**：在 [-1,1]² 撒点，数落在 \(x^2+y^2\le 1\) 里的比例，乘 4。
- **算期望**：\(\mathbb{E}[f(X)] \approx \frac{1}{N}\sum f(x_i)\)，样本均值收敛到真实期望，方差是 \(\mathrm{Var}(f(X))/N\)。

### MCMC：蒙着眼在雾里探路

前面几招都要求你会采、会包络、会加权。如果目标分布你**只知道相对高低、不知道归一化常数**（贝叶斯后验天天如此），怎么办？

MCMC 的思路是换一个目标：**不追求"一次抽一个独立样本"，而是走出一条路，走得够久，路上踩过的每个位置就是一个样本。**

Metropolis-Hastings 的走法：

```text
目标 p(x)（只知道形状，不知道归一化常数）
提案 q(x'|x)（给定当前位置，怎么提议下一步）

算法：
  1. 从 x_0 出发
  2. 对 t = 1..T：
     a. 按 q 提议 x' ~ q(x'|x_t)
     b. 算接受比 alpha = [p(x') q(x_t|x')] / [p(x_t) q(x'|x_t)]
     c. 以 min(1, alpha) 的概率接受：
        u < alpha 则 x_{t+1} = x'，否则原地不动 x_{t+1} = x_t
  3. 扔掉前 B 个样本（burn-in）
  4. 剩下的当作样本用
```

用大白话说这条规则：**新地方比现在好，一定去；新地方比现在差，按差多少的比例去，也可能去。** 所以链不会卡死在某个峰上，也不会漫无目的地乱跑——它沿着概率地形游荡，待得久的地方就是概率高的地方。

对称提案（\(q(x'|x)=q(x|x')\)）时，接受比直接简化成 \(p(x')/p(x)\)，这就是最原始的 Metropolis。

**为什么这套规则能保证收敛？** 因为它满足**细致平衡**：

\[
p(x)\,T(x\to y) = p(y)\,T(y\to x)
\]

从 x 走到 y 的概率质量，正好等于从 y 走到 x 的概率质量。两边一平衡，整体分布就不再变化——\(p\) 就是这条链的平稳分布。链跑够久，分布就"沉淀"成 \(p\) 了。

**实践四个注意点：**

- **Burn-in（预热）**：链从随便一个起点出发，最初那截还没进入平稳状态，得扔掉。
- **Thinning（抽稀）**：相邻样本高度自相关，每 k 个取一个，减少重复信息。
- **提案步长**：步子太小，走到哪儿都接受，但几百年也逛不完整个空间；步子太大，几乎全被拒，链原地卡死。这是 MCMC 最核心的调参。
- **最优接受率**：高维高斯提案的经验值大约是 0.234。

> 注：MH 的天才之处在于——它只用到 \(p\) 的**比值**，归一化常数在分子分母里直接约掉了。所以你可以从一个"只知道形状、不知道总面积"的分布里采样。贝叶斯后验这种"算不出归一化常数"的东西，正是它的主场。

### Gibbs 采样：一次只动一个坐标

Gibbs 是 MCMC 的特例，专治多维分布。它不试图在整个空间里乱跳，而是**每次只沿着一个坐标轴更新一个变量**，其他变量全按住不动：

```text
目标 p(x_1, ..., x_d)

每一轮 t：
  x_1^{t+1} ~ p(x_1 | x_2^t, ..., x_d^t)
  x_2^{t+1} ~ p(x_2 | x_1^{t+1}, x_3^t, ..., x_d^t)
  ...
  x_d^{t+1} ~ p(x_d | x_1^{t+1}, ..., x_{d-1}^{t+1})
```

注意它是"轮流更新、立刻生效"——右边的 x 里，前面几个已经是新值了。像下棋时横着走一步、竖着走一步，交替逼近。

前提是你得能从每个**条件分布** \(p(x_i \mid x_{-i})\) 里采样。很多模型正好满足：

- 贝叶斯网络：条件分布从图结构里直接读出来
- 高斯混合：条件还是高斯
- Ising 模型：每个自旋的条件只依赖它的邻居

**接受率恒为 1**——因为从精确的条件分布采样，细致平衡自动成立，不用再掷骰子决定"要不要接受"。

**局限也很明显**：变量之间强相关时，Gibbs 走不快。一次只动一个坐标，没法沿着分布对角线的方向大步挪。这是它跟 MH 相比的短板。

### 温度采样：给模型的"胆量"调档

语言模型给词表中每个 token 算出一个 logit \(z_i\)，softmax 之后变概率。温度就是在 softmax **之前**先把 logits 整体缩放一下：

```text
p_i = exp(z_i / T) / Σ exp(z_j / T)

T = 1.0  ：标准 softmax
T -> 0   ：退化成 argmax（永远选最大的）
T -> inf ：退化成均匀分布（瞎选）
T < 1    ：锐化——更自信、更保守
T > 1    ：平坦——更犹豫、更多样
```

**为什么这么简单一个除法就管用？** 因为 softmax 对"差距"极其敏感。\(z_1=2, z_2=1\) 时两者差 1；T=0.5 之后变成 4 和 2，差距翻倍，softmax 会把绝大部分概率质量都堆给第一名。

实操档位：

- **T = 0**：贪心解码。事实问答、要复现的实验，用它。
- **T = 0.3–0.7**：稍微放飞。写代码通常在这个区间。
- **T = 0.7–1.0**：平衡档。日常对话。
- **T = 1.0–1.5**：创意写作、头脑风暴。
- **T > 1.5**：越来越像胡话，基本没用。

记住一件事：**温度不改变"哪些 token 有可能"，只改变"概率怎么在这堆 token 之间分配"。**

### Top-k：只在前 k 名里抽签

Top-k 的做法很粗暴：**只保留概率最高的 k 个 token，把它们重新归一化，然后在这 k 个里抽。**

```text
k = 1    ：就是贪心
k = V    ：等于不过滤（V 是词表大小）
k = 40   ：典型值，把长尾里那些荒唐 token 砍掉
```

它解决的是"偶尔抽中一个极不可能的 token，然后整段话开始胡说"这个经典事故。

但它有个死板的毛病：**k 是固定的，不管当前上下文有多确定。** 模型此刻信誓旦旦（某个 token 占 95%），k=40 还是硬塞给它 39 个候选；模型此刻一团迷雾（概率摊在 1000 个 token 上），k=40 又粗暴地把 960 个合理选项砍掉了。一个数字应付不了两种局面。

### Top-p（核采样）：攒够 p 就停

核采样把"固定个数"换成"固定概率预算"：**从高到低累加，攒到累计概率超过 p 就停，剩下的全扔。**

```text
p = 0.9 ：保留覆盖 90% 概率质量的那批 token
p = 1.0 ：不过滤
p = 0.1 ：非常严格，接近贪心
```

好处是**集合大小自适应**：模型很确定时，2~3 个 token 就凑满了 90%；模型很迷茫时，可能要 200 个才凑够。所以核采样出的文本通常比 top-k 更自然。这个名字里的"核"（nucleus），指的就是这堆高概率 token 组成的"核心"。

常用组合：

- **T=0.7 + top-p=0.9**：通用默认档
- **T=0.0**：确定性任务
- **T=1.0 + top-k=50**：Fan et al. (2018) 的原始配置

两者可以叠加：先 top-k 砍掉长尾，再对剩下的做 top-p。

### 重参数化技巧：把骰子挪到"外面"

VAE 的流程是：编码器把输入压成一个潜在分布，从这个分布采样出 \(z\)，解码器再把 \(z\) 还原成输入。

问题来了：**采样的那一步是随机的，梯度到这儿就断了。** 而 VAE 偏偏必须靠反向传播训练。

重参数化的解法是把"随机"拆成两段：

```text
普通采样（不可微）：
  z ~ N(mu, sigma^2)
  随机性卡在中间，梯度流不过去

重参数化采样：
  eps ~ N(0, 1)          # 随机源，跟参数毫无关系
  z = mu + sigma * eps   # 参数的确定性、可微变换
  dz/dmu = 1, dz/dsigma = eps   # 梯度畅通
```

为什么等价？因为 \(N(\mu,\sigma^2)\) 和 \(\mu+\sigma\cdot N(0,1)\) 是同一个分布——正态分布本来就可以"标准化"成"均值加标准差乘噪声"。

这一步的意义在于：**随机性被挪到了一个"没有参数"的地方（eps），而样本变成了参数的确定性函数。** 骰子还是那个骰子，但它现在站在梯度路径之外；梯度只需要穿过那条 \(z=\mu+\sigma\varepsilon\) 的可微通道。

VAE 的完整训练循环：

1. 编码器对每个输入输出 \(\mu\) 和 \(\log\sigma^2\)
2. 采一个 $\varepsilon\sim N(0,1)$
3. \(z = \mu + \sigma\varepsilon\)
4. 解码 \(z\)，重建输入
5. 反传穿过 4→3→2→1（第 3 步可微，所以能走通）

没有这个技巧，VAE 根本没法用标准反向传播训练。它不是一个"优化小技巧"，而是 VAE 成立的前提。

> 注：一句话记住——**把随机性放进一个不参与求导的噪声源 ε，把"带参数的变换"留成可微的。** 随机的那部分不归梯度管，确定的那部分归梯度管，两边各司其职。

### Gumbel-Softmax：让"抽类别"也可微

重参数化只对连续分布（高斯）有效。要抽**离散类别**（比如"选哪个词"），梯度依然过不去。Gumbel-Softmax 给出一个可微的近似。

先看不可微但精确的那一半，**Gumbel-Max**：

```text
从 log 概率 log(p_i) 采样一个类别：
  1. 每个类采一个 g_i ~ Gumbel(0,1)   （g = -log(-log(u))，u ~ Uniform(0,1)）
  2. 返回 argmax(log(p_i) + g_i)

结果：精确服从 p 的分类样本
```

人话：**给每个类的分数加一点噪声，然后选加完噪声后最高的那个。** 噪声的分布选得巧，这个"抢最大"的动作就等价于按概率抽签——概率高的更常抢到，但概率低的也有机会。这是采样里一个特别漂亮的等价关系。

问题在于 `argmax` 是个台阶，没有梯度。于是把它换成一个"软"版本：

```text
用带温度的 softmax 替代硬 argmax：
  y_i = exp((log(p_i) + g_i) / tau) / Σ exp((log(p_j) + g_j) / tau)

tau -> 0   ：接近 one-hot（硬）
tau -> inf ：接近均匀（软）
tau = 1.0  ：温和的软化
```

\(tau\) 就是"软化程度"旋钮。输出从"硬 one-hot 向量"变成了"概率向量"，梯度终于能穿过去了。

实际训练常配 **straight-through 估计器**：前向传播用硬 argmax（保证下游拿到的是真正的离散样本），反向传播借用软版本的梯度。相当于"走的时候走硬路，训的时候按软路的坡度调"。

**用在哪**：VAE 的离散隐变量、神经架构搜索、硬注意力、离散动作的强化学习。

### 分层采样：给靶子画格子，每格必射一箭

普通蒙特卡洛是"随手撒"，撒得不好就会在东边堆一团、西边一个大空档。分层采样强制均匀覆盖：

```text
普通 MC：从 [0,1] 均匀采 N 点，可能成簇，也可能留空

分层：把 [0,1] 切成 N 等份 [0,1/N), [1/N,2/N), ...
      每一层里随机采一个点
      x_i = (i + u_i) / N,  u_i ~ Uniform(0,1)
```

一层一个，谁也跑不出自己那一格。方差**永远不会更差**：

\[
\mathrm{Var}(\text{分层}) \le \mathrm{Var}(\text{普通 MC})
\]

函数越平滑，改进越大；分段常数的函数，分层采样甚至能做到**精确**（因为每层内部函数值不变，采样点落哪儿都一样）。

用在哪：数值积分、训练集切折时保证每折类别均衡（分层 K 折）、NeRF 沿相机光线的分层采样。

### 和扩散模型的联系

扩散模型生图，整个骨架就是采样：前向过程在 T 步里往图上加高斯噪声，直到变成纯噪声；反向过程学一个去噪器，一步步把噪声还原成图。

```text
前向（固定公式，不用学）：
  x_t = sqrt(alpha_t) * x_{t-1} + sqrt(1 - alpha_t) * eps,   eps ~ N(0, I)
  走完 T 步：x_T ~ N(0, I)   （纯噪声）

反向（学出来的）：
  x_{t-1} = (1/sqrt(alpha_t)) * (x_t - (1-alpha_t)/sqrt(1-alpha_bar_t) * eps_theta(x_t, t)) + sigma_t * z
  z ~ N(0, I)

每一步去噪，都是一次采样
```

对照这一课学过的东西：

- 每一步的"采样噪声再确定性地变换"，就是**重参数化技巧**
- 噪声调度 \(\{\alpha_t\}\) 本质上是一个**温度退火**过程
- 训练目标用**蒙特卡洛**估计近似 ELBO
- 反向的祖先采样是一条**马尔可夫链**（每步只依赖当前状态）

所以整张图的生成，可以概括成一句话：**从一团噪声出发，反复"采一点新噪声 + 做一次确定性的去噪"，每次都比上一次干净一点点。**

## 关键术语

| 术语 | 人们常说 | 实际含义 |
|------|---------|---------|
| 采样 | "抽个随机值" | 按概率分布生成取值，所有生成式 AI 的底层机制 |
| 均匀分布 | "等可能的" | [a,b] 内每点密度 1/(b-a)，所有采样方法的起点 |
| 逆 CDF | "概率变换" | F⁻¹(U) 把均匀样本变成任意已知 CDF 的分布样本，精确且高效 |
| 拒绝采样 | "提案-接受/拒绝" | 用简单分布提案，按目标/提案的比值决定收不收，精确但浪费 |
| 重要性采样 | "给样本重新加权" | 用 q 的样本估 p 下的期望，权重 p/q，PPO 的核心 |
| 蒙特卡洛 | "样本平均" | 用样本平均近似积分，误差 O(1/√N) 且与维度无关 |
| MCMC | "会收敛的随机游走" | 构造一条平稳分布恰好是目标的马尔可夫链，MH 是最基础的那个 |
| Metropolis-Hastings | "上坡必走，下坡有时走" | 提议移动、按密度比决定去留，靠细致平衡保证收敛 |
| Gibbs 采样 | "一次只动一个变量" | 按住其余变量，从条件分布更新当前变量，接受率 100% |
| 温度 | "自信旋钮" | softmax 前把 logits 除以 T，T<1 变锐利，T>1 变平坦 |
| Top-k | "只留前 k 名" | 保留概率最高的 k 个 token，重新归一化后采样 |
| 核采样 (top-p) | "攒够概率就停" | 保留累计概率刚超过 p 的最小集合，大小自适应 |
| 重参数化技巧 | "把随机性挪出去" | z = μ + σε，ε~N(0,1)，让采样可微，VAE 训练的必需品 |
| Gumbel-Softmax | "可微的分类采样" | Gumbel 噪声 + 带温度的 softmax，近似硬采样 |
| 分层采样 | "强制覆盖" | 把采样空间切层、每层采一点，方差永远不劣于朴素 MC |
| Burn-in | "预热期" | 链进入平稳状态前扔掉的那些早期样本 |
| 细致平衡 | "可逆条件" | p(x)T(x→y) = p(y)T(y→x)，是 p 为平稳分布的充分条件 |
| 扩散采样 | "迭代去噪" | 从纯噪声出发，反复应用学到的去噪步生成数据 |
