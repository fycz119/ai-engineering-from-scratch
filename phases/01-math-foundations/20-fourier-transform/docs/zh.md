# Fourier 变换

> 任何信号都是一堆正弦波叠出来的。傅里叶变换负责告诉你——叠了哪几根。

**类型：** 构建
**语言：** Python
**先修知识：** 第1阶段，第01-04课、第19课（复数）
**时间：** 约90分钟

## 学习目标

- 从零写出 DFT，并和 \(O(N\log N)\) 的 Cooley-Tukey FFT 对照验证
- 会读频率系数：从里面抽出幅度、相位、功率谱
- 用卷积定理把"滑动相加"变成"频域相乘"，也就是靠 FFT 做卷积
- 把傅里叶分解接到 Transformer 位置编码和 CNN 卷积层上

## 问题

一段录音，本质是"随时间的压强测量序列"；股价，是"随天数变化的一个数"；图片，是"空间上排成网格的亮度"。这些都是**时域**（或空域）数据。

但很多规律在时域里根本看不见：

- 这段音频是单音，还是三根弦一起响？
- 这只股票有没有"每七天一轮"的周期？
- 这张图有没有重复的纹理？

这些问题的答案都是**频率内容**，而时域把它们藏起来了。

傅里叶变换做的就是这件事：把数据从时域搬到频域，拆成一堆不同频率的正弦波，每根波都有自己的**幅度**（有多强）和**相位**（从哪儿起步）。它把这两个都交给你。

为什么 ML 要学这个？因为频域思维到处都在：CNN 的卷积就是频域乘法；Transformer 的位置编码是频率分解；音频模型（语音识别、音乐生成）吃的是频谱图；时序模型在找周期。学会傅里叶，你才有词儿描述这些。

## 概念

### DFT：拿 N 根音叉挨个去测

给定 N 个样本 \(x[0..N-1]\)，DFT 吐出 N 个频率系数 \(X[0..N-1]\)：

\[
X[k]=\sum_{n=0}^{N-1}x[n]\,e^{-2\pi ikn/N},\qquad k=0,\dots,N-1
\]

每个 \(X[k]\) 都是复数。**模 \(|X[k]|\) 是这个频率有多强，辐角 \(\arg X[k]\) 是它的相位。**

先别被求和号吓到，它的动作非常朴素：

> \(e^{-2\pi ikn/N}\) 是一个"每 N 个样本转 k 圈"的匀速旋转指针。你把信号和这个指针**逐点对齐、相乘、求和**——也就是做一次相关性测量。信号里如果真有这个频率的成分，对齐的过程中它一直"同频共振"，加起来就很大；如果没有，正负抵消，结果趋近于零。

**所以 DFT 就是拿 N 根转速各不相同的音叉，挨个贴到信号上测共振。** 每个音叉返回一个复数：一个说"有多响"，一个说"从哪个角度起振"。

### 每个系数在说什么

**\(X[0]\)：直流分量。** 它等于所有样本之和，正比于信号的均值。也就是"整段信号整体被抬高了多少"这个零频偏移。

**\(X[k]\)（\(1\le k\le N/2\)）：正频率。** 第 k 个系数对应"整个窗口内转 k 圈"的波，周期是 \(N/k\) 个样本。k 越大，振荡越快。

**\(X[N/2]\)：Nyquist 频率。** 这是 N 个采样点所能表示的最高频率。再快的振荡，这套采样就抓不住了，会被伪装成低频——这就是混叠。

**\(X[k]\)（\(N/2<k<N\)）：负频率。** 对实值信号，有 \(X[N-k]=\overline{X[k]}\)。也就是说后半段是前半段的镜像，全是冗余。

**结论：对实信号，真正有用的信息只有前 \(N/2+1\) 个系数。**

> 注：这条"共轭对称"性质是 `rfft` 只返回 \(N/2+1\) 个点的原因。实信号本就没有那么多独立信息，堆在后面的都是复数的另一半——镜像出来的。

### 逆 DFT：换个坐标系，信息一点没少

从频率系数把原信号拼回来：

\[
x[n]=\frac{1}{N}\sum_{k=0}^{N-1}X[k]\,e^{2\pi ikn/N},\qquad n=0,\dots,N-1
\]

和正变换只差两点：指数符号变正，前面多一个 \(1/N\)。

**逆 DFT 是完美重建，没有任何信息损失。** 因为 DFT 根本不是"压缩"或"归纳"，它是一次**基变换**——同一份信息，换了一套坐标轴重新写一遍。就像同一段音乐，你可以谱成五线谱，也可以谱成简谱，信息完全相同，只是看起来不一样。

### FFT：把 O(N²) 变成 O(N log N)

照着定义算，DFT 是 \(O(N^2)\)：N 个输出，每个都要对 N 个输入求和。N=100 万时，是 \(10^{12}\) 次运算——太多了。

FFT 算出**完全相同**的结果，只要 \(O(N\log N)\)。N=100 万时大约 \(2\times 10^7\) 次。**这才是频率分析能真正落地的原因**——它不是一个"优化"，它是从"不可用"到"可用"的跨越。

最有名的是 Cooley-Tukey 算法，思路是分治：

1. 把信号按**偶数下标**和**奇数下标**拆成两半。
2. 递归地对两半分别算 DFT。
3. 用"旋转因子" \(e^{-2\pi ik/N}\) 把结果合并回去。

```text
X[k]       = E[k] + e^{-2πik/N} O[k]        k = 0..N/2-1
X[k + N/2] = E[k] - e^{-2πik/N} O[k]        k = 0..N/2-1

E = 偶数部分样本的 DFT
O = 奇数部分样本的 DFT
```

注意两行只差一个正负号——**算出一个，另一个白送。** 这个对称性就是省下那一半运算量的地方。每层递归的合并工作量是 \(O(N)\)，一共 \(\log_2 N\) 层，于是总复杂度：

\[
T(N)=2T(N/2)+O(N)=O(N\log N)
\]

FFT 一般要求长度是 2 的幂，实践中把信号补零到下一个 2 的幂即可。

> 注：FFT 的魔法就两件事——**分治**把问题砍半，**对称性**让两个半问题的答案能"一正一负"地拼回来，省掉一半计算。这是算法设计里的经典胜利，快得毫无争议。

### 频谱怎么看

**功率谱**：\(|X[k]|^2\)。每个频率的能量，这是绝大多数分析的关注点。

**相位谱**：\(\arg X[k]\)。每个频率的起点角度——很多任务直接忽略它（人耳对相位也不敏感）。

```text
P[k] = |X[k]|² = X[k].real² + X[k].imag²
phi[k] = atan2(X[k].imag, X[k].real)
```

### 频率分辨率：你能分得多细

```text
第 k 个频率 bin 对应的频率：f_k = k * fs / N
频率分辨率：δf = fs / N
能表示的最高频率：f_max = fs / 2   （Nyquist）
```

翻译一下：

- 想分辨两个**挨得很近**的频率 → 需要更长的观测窗口（更大的 N）。
- 想看到**很快**的振荡 → 需要更高的采样率（更大的 fs）。

这两件事是独立的，不能互相冒充。

### 卷积定理：滑动相加 ⇔ 频率各乘一个系数

这是信号处理里最重要的一条结论，而且和 CNN 直接挂钩：

**时域上的卷积，等于频域上的逐点相乘。**

\[
x*h=\mathrm{IFFT}\big(\mathrm{FFT}(x)\cdot \mathrm{FFT}(h)\big)
\]

为什么这条如此重要？看成本：

- 直接卷积：\(O(N\cdot M)\)
- 走 FFT：\(O(N\log N)\)

核（M）越大，FFT 的优势越明显。**大感受野的卷积层，本质上就是在做这件事。**

用一个物理画面理解它：声音穿过音乐厅，混响相当于给每个频率各自乘了一个"这面墙对这个音高的吸收系数"。时域看是"一遍遍回声叠加"（卷积），频域看只是"每个频率的振幅各乘一个数"（乘法）。同一件事，两副面孔。

注意一个细节：**DFT 算出的是循环卷积**（信号会首尾绕回去）。要的是"不绕"的线性卷积，就得在变换前把两个信号都补零到 \(N+M-1\) 的长度。

### 窗函数：剪一段音乐，剪口会"啪"一声

DFT 有个隐含假设：**这 N 个样本是一个无限重复信号的其中一段。** 也就是说，它默认第 N 个样本之后立刻接回第 0 个。

如果信号首尾的值差得远，这个"接缝"就是一个突变。突变里含有大量高频成分，会在频谱上撒出一片本不存在的假信号——**频谱泄露**。

解法很朴素：**在两端做淡入淡出**，让首尾都收到 0，接缝就平滑了。这就是窗函数。

| 窗 | 形状 | 主瓣宽度 | 旁瓣 | 用在哪 |
|----|------|---------|------|-------|
| 矩形 | 平的（等于不加窗） | 最窄 | 最高（-13dB） | 信号在 N 内恰好整周期 |
| Hann | 升余弦 | 中等 | 低（-31dB） | 通用频谱分析 |
| Hamming | 改良余弦 | 中等 | 更低（-42dB） | 音频、语音 |
| Blackman | 三余弦 | 宽 | 极低（-58dB） | 旁瓣必须压死时 |

```text
Hann：    w[n] = 0.5(1 - cos(2πn/(N-1)))
Hamming： w[n] = 0.54 - 0.46 cos(2πn/(N-1))
```

用法就是把信号逐点乘以窗，再做 DFT：`X = DFT(x * w)`。

这里有个必然的权衡：**主瓣越窄（分得越清），旁瓣就越高（漏得越多）**。所以选窗取决于你更在意"分辨两个近邻频率"，还是"别让强信号的旁瓣盖住弱信号"。

### DFT 的几条基本性质

| 性质 | 时域 | 频域 |
|------|------|------|
| 线性 | \(ax+by\) | \(aX+bY\) |
| 时移 | \(x[n-k]\) | \(X[f]e^{-2\pi ifk/N}\)（只改相位） |
| 频移 | \(x[n]e^{2\pi if_0n/N}\) | \(X[f-f_0]\)（整体挪位置） |
| 卷积 | \(x*h\) | \(X\cdot H\)（逐点乘） |
| 逐点乘 | \(x\cdot h\) | \(X*H\)（循环卷积，带 1/N） |
| Parseval | \(\sum|x[n]|^2\) | \((1/N)\sum|X[k]|^2\) |
| 共轭对称（实输入） | \(x[n]\) 为实 | \(X[k]=\overline{X[N-k]}\) |

Parseval 定理可以理解成**能量守恒**：不管你在时域还是频域用平方和度量总能量，结果除以 N 之后一模一样。换坐标系不会凭空造出或吞掉能量。

### 和位置编码的联系

原版 Transformer 的正弦位置编码：

```text
PE(pos, 2i)   = sin(pos / 10000^{2i/d_model})
PE(pos, 2i+1) = cos(pos / 10000^{2i/d_model})
```

每一对维度 \((2i, 2i+1)\) 就是一个特定频率的振荡器，频率从高（前面的维度）到低（后面的维度）按几何级数铺开。

这套设计的三条关键属性：

- **唯一性**：没有两个位置的编码完全相同——每个位置都有自己的一套"相位组合"。
- **有界**：sin/cos 永远落在 [-1,1]，数值不会炸。
- **相对位置可表达**：位置 \(p+k\) 的编码可以由位置 \(p\) 的编码经一个**线性变换**（本质是旋转）得到。所以模型能学会"关心相对距离"。

这跟傅里叶系数的逻辑是同一个：**一组不同频率的系数，可以唯一地标识一个信号。** 位置编码无非是把"位置"当成要标识的信号。

### 和 CNN 的联系

卷积层做的事，数学上就是"拿一个学到的核在输入上滑动并逐点相乘求和"——就是卷积。

而卷积定理告诉你等价路径：

1. 对输入做 FFT
2. 对核做 FFT
3. 频域逐点相乘
4. 逆变换回来

普通 CNN 用直接卷积，因为 3×3 这种小核直接算更快（FFT 有固定开销）。但核很大、或者要做全局卷积时，FFT 路径就赢得明显。

甚至有架构（FNet）干脆**完全用 FFT 替换注意力**：不加任何参数，就用 \(O(N\log N)\) 的变换拿到了和 \(O(N^2)\) 自注意力相当的精度。

### 频谱图与 STFT：从"有什么"到"什么时候有"

单次 FFT 只告诉你整段信号里有哪些频率，**但完全不知道它们什么时候出现。**

一段"呜——"的扫频音（频率从低到高滑）和一整段和弦（所有频率同时存在），幅度谱可以长得一模一样。区别全在时间上。

STFT（短时傅里叶变换）的解法就是**把长信号切成一小段一小段，每段各自做 FFT**：

```text
STFT 流程：
1. 定窗口长度（例如 1024 个样本）
2. 定 hop（步进，例如 256 个样本，也就是 75% 重叠）
3. 每个窗口位置：截一段 → 乘 Hann/Hamming 窗 → 做 FFT → 把幅度谱存成图的一列
```

结果就是**频谱图**：一张二维图，横轴时间、纵轴频率，每个点的明暗表示"那一刻那个频率有多强"。

这是音频 ML 的标准输入。语音识别（Whisper、DeepSpeech）吃的都是 **mel 频谱图**——频率轴按 mel 尺度重新映射，更贴合人耳对音高的感知方式（人耳对低频的分辨比高频细得多，等间距的 Hz 轴并不合理）。

### 混叠：为什么电影里的车轮会倒着转

如果信号里含有高于 \(f_s/2\)（Nyquist）的频率，用 \(f_s\) 采样就会造出一个"假的低频副本"。

```text
真实信号 90Hz，采样率 100Hz
表观频率 = 100 - 90 = 10Hz
采样出来的点和真正的 10Hz 信号完全一致
→ 凭这批样本，你永远分不出它是 90 还是 10
```

这就是**混叠**。你在电影里见过的"车轮倒转"就是同一件事：摄像机每秒拍 24 帧，轮子的转速超过了采样率能表达的上限，于是看起来在慢慢倒着转。

所以 ADC 前面一定有个抗混叠滤波器，先把 Nyquist 以上的频率物理删掉，再采样。

ML 里也有同一个坑：下采样特征图时如果没做低通滤波，高频就会折叠成假的低频纹理。有些架构专门加了抗混叠池化层来治它。

### 补零不能提高分辨率

一个常见误解：做 FFT 之前补一堆零，频谱就变精细了。

**不会。补零只是在已有的频率点上做插值**，让你的曲线看起来更光滑、点更密，但它**不可能揭示原样本里根本不存在的频率细节**。

真正的频率分辨率只有一个决定因素——**观测时长** \(T=N/f_s\)。要分辨间隔为 \(\delta f\) 的两个频率，你至少需要 \(T=1/\delta f\) 秒的数据。这是硬约束，补零改不了。

就像把一张模糊的照片放大到 4K：像素多了，细节并不会变清楚。

## 练习

1. **认音。** 造一个频率未知（1~50Hz 之间）的纯正弦，用 128Hz 采 1 秒，用 DFT 把频率找出来并验证。然后加上 σ=0.5 的高斯噪声重做一遍，观察噪声怎么改变频谱。
2. **FFT vs DFT。** 生成长度 64 的随机信号，分别用 DFT 和 FFT 算，验证系数差小于 1e-10。再在 256 / 512 / 1024 / 2048 四种长度上计时，画出 DFT/FFT 的时间比曲线。
3. **卷积定理。** 取 \(x=[1,2,3,4,0,0,0,0]\)、\(h=[1,1,1,0,0,0,0,0]\)。先直接算循环卷积，再走 FFT（变换→相乘→逆变换），验证两者一致。然后做正确的零填充，得到线性卷积。
4. **窗函数的效果。** 造 10Hz 和 12Hz 两个正弦的叠加（挨得很近），128Hz 采 1 秒。分别用无窗、Hann、Hamming 算功率谱。哪个窗最容易把两个峰分开？为什么？
5. **解剖位置编码。** 生成 \(d_{model}=128\)、\(max\_pos=512\) 的正弦位置编码，对每一对位置 \((p_1,p_2)\) 算编码的点积。验证点积只依赖 \(|p_1-p_2|\)、与绝对位置无关。再观察距离变大时点积怎么变化。

## 关键术语

| 术语 | 含义 |
|------|------|
| DFT | 离散傅里叶变换，N 个时域样本 → N 个频域系数，每个系数是与该频率复正弦的相关性 |
| FFT | 用 \(O(N\log N)\) 算出 DFT 的算法，Cooley-Tukey 靠偶/奇拆分递归 |
| 逆 DFT | 从频率系数重建时域信号，公式与正变换相同但指数变号并除以 N |
| 频率 bin | 输出下标 k 对应的频率是 \(k\cdot f_s/N\) Hz |
| 直流分量 | \(X[0]\)，零频系数，正比于信号均值 |
| Nyquist 频率 | \(f_s/2\)，给定采样率下能表示的最高频率，超过就混叠 |
| 功率谱 | \(\|X[k]\|^2\)，每个频率的能量分布 |
| 相位谱 | \(\arg X[k]\)，每个频率的起点相位，分析中常被忽略 |
| 频谱泄露 | 把非周期信号当周期处理导致的虚假频率成分，靠窗函数减轻 |
| 窗函数 | DFT 之前乘上去的锥形函数（Hann/Hamming/Blackman），用来压泄露 |
| 旋转因子 | FFT 蝶形运算里合并子 DFT 的那个复指数 \(e^{-2\pi ik/N}\) |
| 卷积定理 | 时域卷积等于频域逐点相乘，信号处理和 CNN 的地基 |
| 循环卷积 | 信号首尾绕回来的卷积，正是 DFT 天然算出来的东西 |
| 线性卷积 | 不绕回的标准卷积，靠零填充实现 |
| Parseval 定理 | 能量守恒：\(\sum\|x[n]\|^2=(1/N)\sum\|X[k]\|^2\) |
| 混叠 | 频率高于 Nyquist 时，因采样不足被伪装成低频 |
