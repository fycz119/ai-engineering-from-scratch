# 机器学习中的统计学

> 统计学告诉你模型是真的有效，还是只是运气好。

**类型：** 构建
**语言：** Python
**先修知识：** 第1阶段，第06课（概率与分布）、第07课（贝叶斯定理）
**时间：** 约120分钟

## 学习目标

- 从零计算描述统计、Pearson/Spearman 相关、协方差矩阵
- 执行假设检验（t 检验、卡方检验），正确解读 p 值与置信区间
- 用 Bootstrap 重采样为任意指标构建无分布假设的置信区间
- 用效应量区分统计显著与实际显著

## 问题

你训练了两个模型。A 得 0.87，B 得 0.89。你部署 B。三周后生产指标反而更差。发生了什么？

B 并没有真正优于 A。0.02 的差异是噪声。测试集太小或方差太高。你把随机性包装成了改进。

这每天都在发生：Kaggle 排行榜抖动、论文无法复现、基于几百样本就宣布胜者的 A/B 测试。根因相同：有人跳过了统计学。

统计学给你区分信号与噪声的工具：差异是否真实、有多大把握、需要多少数据才能信任结果。每个 ML 流水线、模型比较、实验都需要统计学。没有它，你在猜。

## 概念

### 描述统计：概括数据

建模前先了解数据长什么样。描述统计把数据集压缩为几个捕捉其形状的数字。

**集中趋势**回答“中间在哪？”：

```
均值：所有值之和 / 个数  mu = (1/n) sum x_i
中位数：排序后的中间值，抗异常值。[1,2,3,4,1000] 均值 202，中位数 3。
众数：出现最多的值，分类数据有用；连续数据很少信息量。
```

均值是平衡点，中位数是中点。两者发散说明分布偏斜。收入分布均值 >> 中位数（右偏，亿万富翁拖尾）；训练损失常均值 << 中位数（左偏，简单样本多）。

**离散程度**回答“数据多分散？”：

```
方差：与均值偏差的平方平均  sigma^2 = (1/n) sum (x_i - mu)^2
标准差：方差平方根，单位与数据相同，更直观
极差：max - min，对异常值敏感，几乎从不单独有用
IQR：Q3 - Q1（四分位距），中间 50% 的范围，抗异常值
```

**分位数**把排序数据等分为 100 份。第 25 百分位（Q1）表示 25% 的值低于此。第 50 是中位数，第 75 是 Q3。

```
延迟监控：
  P50 = 中位数延迟（典型体验）
  P95 = 第95百分位（差但非最坏）
  P99 = 第99百分位（尾延迟，常是中位数 10 倍）
```

ML 中你关心分位数：推理延迟、预测置信度分布、误差分布。平均误差低但 P99 很差的模型，在安全关键应用中可能无用。

**样本 vs 总体统计。** 从样本算方差时除以 (n-1) 而非 n（Bessel 校正），补偿样本均值不是真实总体均值的事实。除以 n 会系统性低估真方差；除以 (n-1) 无偏。

```
总体方差: sigma^2 = (1/N) sum (x_i - mu)^2
样本方差: s^2     = (1/(n-1)) sum (x_i - x_bar)^2
```

实践中：n 大（数千）时差异可忽略；n 小（几十）时 mattered。

> 注：Bessel 校正的直觉：样本均值是“贴着数据”算的，偏差平方和比真实均值时小，所以除以 n 会低估；(n-1) 把自由度补回来。n 越大校正越小。

### 相关：变量如何共同变化

相关衡量两个变量线性关系的强度与方向。

**Pearson 相关系数**衡量线性关联：

```
r = sum((x_i - x_bar)(y_i - y_bar)) / (n * s_x * s_y)
r = +1 完美正线性；r = -1 完美负线性；r = 0 无线性（但可能有非线性！）
范围 [-1,1]
```

Pearson 假设关系线性、两变量近似正态，对异常值敏感。单个极端点能把 r 从 0.1 拉到 0.9。

**Spearman 秩相关**衡量单调关联：

```
1. 每个值替换为秩（1,2,3,...）
2. 在秩上算 Pearson
Spearman 捕捉任何单调关系，不仅线性。y=x^3 时 Pearson r<1，Spearman rho=1。
```

何时用哪个：

```
Pearson: 两变量连续且近似正态；只关心线性关系；无极端异常值
Spearman: 序数数据（排名、评分）；非正态；怀疑单调但非线性；有异常值
```

黄金法则：相关不蕴含因果。冰淇淋销量与溺水死亡相关，因为两者都随夏天上升。模型准确率与参数数量相关，但加参数不自动提准确率（见：过拟合）。

> 注：Pearson 对异常值敏感是因为它用均值与方差，而均值/方差本身就被异常值扭曲。Spearman 用秩，把极端值变成“最大秩”，影响有界。

### 协方差矩阵

协方差衡量两个变量如何共同变化：

```
Cov(X,Y) = (1/n) sum (x_i - x_bar)(y_i - y_bar)
>0: X,Y 倾向同增；<0: X 增 Y 减；=0: 无线性共动
```

对 d 个特征，协方差矩阵 C 是 d×d，C[i][j]=Cov(feature_i, feature_j)。对角线 C[i][i] 是各特征方差。

```
C = | Var(x1) Cov(x1,x2) Cov(x1,x3) |
    | Cov(x2,x1) Var(x2) Cov(x2,x3) |
    | Cov(x3,x1) Cov(x3,x2) Var(x3)  |
性质：对称；半正定（特征值>=0）；对角=方差；非对角=协方差
```

与 PCA 的联系：PCA 对协方差矩阵做特征分解。特征向量是主成分（最大方差方向），特征值表示每个成分捕获的方差。这就是第10课的内容，但现在你看到为什么协方差矩阵是正确的分解对象：它编码了数据中所有成对线性关系。

与相关的联系：相关矩阵是标准化变量（除以标准差）的协方差矩阵，把协方差归一化到 [-1,1]。

### 假设检验

假设检验是在不确定下做决策的框架。从一个主张出发，收集数据，判断数据是否与主张一致。

**设置：**

```
原假设 H0：默认假设，通常“无效应”
备择假设 H1：你想证明的

例：H0: 模型 A 与 B 准确率相同
    H1: 模型 B 准确率高于 A
```

**p 值**是在 H0 为真时，看到至少与观测数据一样极端的数据的概率。它**不是** H0 为真的概率。这是统计学中最常见的误解。

```
p-value = P(数据这么极端 | H0 为真)
若 p-value < alpha（通常 0.05）：拒绝 H0，结果“统计显著”
若 p-value >= alpha：未能拒绝 H0，证据不足；这不意味着 H0 为真
```

**置信区间**给出参数的合理值范围：

```
均值的 95% 置信区间：x_bar +/- z * (s / sqrt(n))，z=1.96（95%）
解释：若重复实验多次，95% 的计算出的区间包含真实均值。
它不意味着真实均值有 95% 概率落在此具体区间。
```

置信区间宽度反映精度：宽=不确定高；窄=估计精确（但数据有偏时不一定准确）。

> 注：p 值的常见误解：p=0.03 不是“H0 有 3% 概率真”，而是“若 H0 真，看到这么极端数据的概率 3%”。p 值小说明数据与 H0 不符，不直接给 H0 的概率。要 H0 的概率需要贝叶斯。

### t 检验

t 检验比较均值，有几种形式。

**单样本 t 检验：** 总体均值是否不同于假设值？

```
t = (x_bar - mu_0) / (s / sqrt(n))，自由度 = n - 1
```

**双样本 t 检验（独立）：** 两组均值是否不同？

```
t = (x_bar_1 - x_bar_2) / sqrt(s1^2/n1 + s2^2/n2)
这是 Welch t 检验，不假设等方差。除非有特殊理由，一律用 Welch。
```

**配对 t 检验：** 测量成对出现时（同一模型在同一数据分割上评估）：

```
d_i = x_i - y_i，然后对 d_i 做单样本 t 检验，mu_0=0
```

ML 中配对 t 检验常见：两模型跑相同 10 折交叉验证，成对比较分数。

### 卡方检验

卡方检验检查观测频率是否匹配期望频率，用于分类数据。

```
chi^2 = sum((observed - expected)^2 / expected)

例：模型输出分布是否匹配训练分布？
类别   观测  期望
正面   120   100
负面    80   100
chi^2 = (120-100)^2/100 + (80-100)^2/100 = 4+4=8
自由度 1 时，chi^2=8 给出 p<0.005，差异显著。
```

### ML 模型的 A/B 测试

ML 的 A/B 测试与网页 A/B 测试不同，模型比较有特殊挑战：

```
1. 相同测试集：两模型必须在相同数据上评估，不同测试集比较无意义
2. 多指标：准确率不够，需要 precision/recall/F1/延迟/公平性
3. 方差：用交叉验证或 bootstrap 估计各指标方差，而非点估计
4. 数据泄露：测试集用于模型选择则比较有偏，保留最终测试集
```

**流程：**

```
1. 定义指标与显著性水平 alpha=0.05
2. 两模型跑相同 k 折交叉验证
3. 收集配对分数 [(a1,b1),...,(ak,bk)]
4. 差异 d_i = b_i - a_i
5. 对差异做配对 t 检验
6. 均值差异是否显著不为 0？
7. 计算均值差异的置信区间
8. 计算效应量（Cohen's d）判断实际显著
```

### 统计显著 vs 实际显著

结果可以统计显著但实际无意义。数据足够多时，微小差异也会统计显著。

```
例：A 准确率 0.9234，B 0.9237，n=1,000,000，p=0.001
统计显著？是。实际显著？0.03% 提升不值得部署新模型的成本。
```

**效应量**量化差异大小，与样本量无关：

```
Cohen's d = (mean_1 - mean_2) / pooled_std
d=0.2 小效应；d=0.5 中效应；d=0.8 大效应
```

永远同时报告 p 值与效应量。p 值说差异是否真实，效应量说是否重要。

> 注：大 n 让 p 值“作弊”：标准误 ~1/sqrt(n)，n 大时任何微小差异都显著。所以必须看效应量/置信区间宽度，不能只看 p 值。

### 多重比较问题

测很多假设时，有些会“显著”纯属偶然。测 20 件事、alpha=0.05，即使全无真实效应，也期望 1 个假阳性。

```
P(至少一个假阳性) = 1 - (1-alpha)^m
m=20, alpha=0.05: P=1-0.95^20=0.64
```

**Bonferroni 校正：** alpha 除以测试数。

```
adjusted alpha = 0.05/20 = 0.0025，仅当 p<0.0025 才拒绝 H0
保守但简单，适用于独立测试
```

ML 中：跨多指标比较模型、测多超参配置、在多数据集上评估时都 mattered。

### Bootstrap 方法

Bootstrap 通过有放回重采样估计统计量的抽样分布，无需分布假设。

**算法：**

```
1. 你有 n 个数据点
2. 有放回抽 n 个（某些点重复，某些不出现）
3. 在 bootstrap 样本上计算统计量
4. 重复 B 次（通常 1000-10000）
5. bootstrap 统计量的分布近似抽样分布
```

**Bootstrap 置信区间（百分位法）：**

```
排序 B 个 bootstrap 统计量
95% CI = [第 2.5 百分位, 第 97.5 百分位]
```

**为什么 bootstrap 对 ML 重要：**

```
- 测试集准确率是点估计，bootstrap 给置信区间
- 不能假设指标分布正态（尤其 AUC、F1、P@k）
- 适用于任意统计量：中位数、两均值之比、两模型 AUC 差
- 不需要闭式公式
```

**Bootstrap 模型比较：**

```
1. 两模型在同一测试集的预测
2. 每次 bootstrap：有放回重采样测试索引；算 metric_A、metric_B；存 diff
3. 差异的 95% CI = [diff 的第2.5百分位, 第97.5百分位]
4. CI 不含 0 则差异显著
```

比配对 t 检验更鲁棒，因无分布假设。

### 参数 vs 非参数检验

**参数检验**假设特定分布（通常正态）：

```
t 检验：数据正态（或大 n 由 CLT）
ANOVA：正态且等方差
Pearson r：双变量正态
```

**非参数检验**无分布假设：

```
Mann-Whitney U：两组比较（替代独立 t）
Wilcoxon 符号秩：配对数据（替代配对 t）
Spearman rho：秩相关（替代 Pearson）
Kruskal-Wallis：多组比较（替代 ANOVA）
```

何时非参数：
```
- 小样本（n<30）且明显非正态
- 序数数据（评分、排名）
- 无法移除的重异常值
- 偏斜分布
```

何时参数：
```
- 大样本（CLT 使检验统计量近似正态）
- 数据近似对称无极端异常值
- 统计功效更高
```

ML 实验通常 n 小（5 或 10 折），所以 Wilcoxon 符号秩往往比 t 检验更合适。

### 中心极限定理：实践意义

CLT 说：样本均值的分布随 n 增大趋向正态，无论总体分布如何。

```
X_1,...,X_n iid，均值 mu，方差 sigma^2：
X_bar ~ Normal(mu, sigma^2/n)  当 n->∞
多数情况 n>=30 即可；高度偏斜可能需要 n>=100。
```

对 ML 的意义：
```
1. 为聚合指标的置信区间与 t 检验提供依据
2. 解释为什么即使单折差异大，对折数取平均仍稳定
3. 小批量梯度下降：批量梯度近似真实梯度（CLT 生效）
4. 集成方法：多模型平均比单模型稳定
```

CLT 不做的事：
```
- 不让数据变正态，是样本均值变正态
- 对方差无穷的重尾分布（Cauchy）无效
- 对相关数据（未校正的时间序列）无效
```

### ML 论文中常见统计错误

1. 在训练集上测试 → 过拟合。始终留出模型训练时未见的数据。
2. 无置信区间 → 单一准确率无不确定性，不可复现。
3. 忽略多重比较 → 测 50 配置报最优，假阳性膨胀。
4. 混淆统计与实际显著 → 0.001 的 p 值对应 0.01% 提升无意义。
5. 不平衡数据用准确率 → 99% 负类时 99% 准确率说明模型什么都没学，用 P/R/F1/AUC。
6. 挑选指标 → 只报模型赢的指标。诚实评估报所有相关指标。
7. 跨 train/test 泄露 → 先归一化再切分，或用未来预测过去。
8. 小测试集无方差估计 → 100 样本上声称 2% 提升是噪声。
9. 假设独立但数据不独立 → 同一患者的多张图、同文档多句，组内观测相关。
10. P-hacking → 不断换检验/子集/排除标准直到 p<0.05，结果是搜索产物。
