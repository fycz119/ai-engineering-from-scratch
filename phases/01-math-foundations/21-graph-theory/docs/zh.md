# 机器学习中的图论

> 图是"关系"的数据结构。数据一旦有连接，表格就不够用了。

**类型：** 构建
**语言：** Python
**先修知识：** 第1阶段，第01-03课（线性代数、矩阵）
**时间：** 约90分钟

## 学习目标

- 把图写成矩阵（邻接矩阵/邻接表），并实现 BFS、DFS 两种遍历
- 算出图 Laplacian，用它的特征值判断图有几个连通块、从哪儿切开最合适
- 手搓一轮 GNN 风格的消息传递（归一化邻接矩阵乘法）
- 用 Fiedler 向量做谱聚类，把图切成两半

## 问题

社交网络、分子结构、知识库、论文引用网、路网——全都是图。

而传统 ML 把数据当一张**平坦表格**：每一行是一个互不相关的样本，每一列是一个特征。这套假设在"连接结构本身就是信号"的时候，彻底失效。

**社交网络**：预测一个用户会买什么，他自己的购买记录当然有用；但**他朋友的购买记录更有用**。连接里带着信息。

**分子**：预测它会不会和某个蛋白结合，原子种类重要；但**原子之间怎么键合**更重要。结构本身就是数据。

图神经网络（GNN）是深度学习里跑得最快的方向之一，撑着药物发现、社交推荐、欺诈检测、知识图谱推理。而所有这些，脚下踩的都是同一块地基：**基础图论**。

你需要的其实就四样东西：

1. 把图写成**矩阵**（这样才能相乘、才能进 GPU）
2. **遍历**算法（这样才能探索结构）
3. **Laplacian**（谱图论里最重要的那个矩阵）
4. **消息传递**（让 GNN 真正跑起来的那一步）

## 概念

### 节点与边：图就是一张关系网

图 \(G=(V,E)\) 由顶点集 V 和边集 E 组成，每条边连着两个节点。

**有向 vs 无向**：无向边 \(u\!-\!v\) 表示双向通道；有向边 \(u\to v\) 只表示从 u 指向 v，反过来不一定成立。

**带权 vs 无权**：无权边只有"有"和"没有"；带权边还带一个数值（距离、成本、亲密度）。

| 图类型 | 例子 |
|--------|-----|
| 无向无权 | 微信/脸书好友关系 |
| 有向无权 | 微博关注关系 |
| 无向带权 | 路网（边的权是距离） |
| 有向带权 | 网页链接（边的权是转移概率） |

### 邻接矩阵：一张打勾的座位表

图最核心的表示方式就是邻接矩阵 A。n 个节点的图，A 是 n×n：

\[
A_{ij}=1 \iff \text{i 到 j 有边}
\]

无向图的 A 是对称的（\(A_{ij}=A_{ji}\)）；带权图的 \(A_{ij}\) 直接填权重。

三角形（三个节点两两相连）长这样：

```text
节点 0,1,2，边 (0,1)、(1,2)、(0,2)

A = [[0, 1, 1],
     [1, 0, 1],
     [1, 1, 0]]
```

**这就是每个 GNN 的输入。** 对 A 做矩阵运算，就等于在图上做某种操作——这个对应关系是整门课的关键。

### 度：一个节点认识多少人

节点的度就是接到它身上的边数；有向图还分入度和出度。

把度排到对角线上，就是**度矩阵** D：

```text
三角形例：D = diag(2, 2, 2)     # 每个节点都连到另外两个
```

度能粗略反映重要性：度越高，越像枢纽。

而**度的分布**能揭示整个网络的性格：

- 社交网络是**幂律分布**——极少数大 V 连接了海量的人，绝大多数人只有几十个好友。尾巴很长。
- 随机图的度接近**泊松分布**——大家都差不多，没有超级枢纽。

### BFS：像石子入水，一圈一圈外扩

**BFS（广度优先）**先看完所有直接邻居，再去看邻居的邻居，一层一层往外推。它用的数据结构是队列（先进先出）。

它的招牌能力：**在无权图里直接给出最短路径。** 因为一个节点第一次被"发现"时所在的层数，恰好就是它离起点的跳数。所以社交网络里的"几度人脉"，本质上就是跑一遍 BFS。

### DFS：走迷宫，一条道走到黑

**DFS（深度优先）**反过来：沿着一个方向一直钻，钻不动了才回头换路。用栈（后进先出）或者递归。

| 算法 | 数据结构 | 擅长找到 | 典型用途 |
|------|---------|---------|---------|
| BFS | 队列 | 最短路径 | 社交距离、知识图谱逐层遍历 |
| DFS | 栈 | 连通块、环 | 连通性判断、拓扑排序 |

DFS 的三件常用活儿：找连通分量（对每个没访问过的点跑一次 DFS）、检测环、拓扑排序。

### 图 Laplacian：衡量"我和邻居差多少"

\[
L = D - A
\]

这是谱图论里最重要的矩阵。三角形那个例子：

```text
D = [[2,0,0],[0,2,0],[0,0,2]]
A = [[0,1,1],[1,0,1],[1,1,0]]

L = [[ 2,-1,-1],
     [-1, 2,-1],
     [-1,-1, 2]]
```

先看这个矩阵有多朴素：对角线上是"我认识几个人"，非对角线上是"−1 表示我认识你"。

但它的行为非常漂亮。看 \(Lx\) 在第 i 个节点的分量：

\[
(Lx)_i = d_i x_i - \sum_{j\sim i} x_j
\]

翻译成人话：**"我这个节点上的值 × 我的度数，减掉所有邻居的值之和"**——也就是"我"和"我的邻居们"之间的差异。

> 更好的画面：假设每个节点有一个温度。\(Lx\) 衡量的是"这个点比周围平均热多少"。所以 Laplacian 是**图上的二阶差分算子**，也是热扩散过程的发动机：热量会从热的地方流向冷的邻居，而 L 描述的正是这个流动的趋势。

它的四条性质，一条比一条有分量：

1. **L 是半正定的**，所有特征值 ≥ 0。
2. **零特征值的个数 = 连通分量的个数。** 整张图连在一起，就恰好 1 个零特征值；如果你有 3 块互不相连的孤岛，就有 3 个零特征值。
3. **最小的非零特征值叫 Fiedler 值，它衡量"这张图连得有多结实"。** 值大 → 连通良好；值小 → 存在一个细腰/瓶颈，一刀就能切断。
4. **Fiedler 值对应的特征向量（Fiedler 向量）直接给出了最佳切法。** 值为正的一堆节点归一边，为负的归另一边。这就是谱聚类。

为什么"零特征值"能数出连通块？因为 L 作用在 x 上问的是"这个值和邻居差多少"。如果一块孤岛上的所有节点取值完全相同，那内部差异处处为 0，Lx 在这块上就是 0——这就是一个零特征向量。**每块孤岛都能提供一个这样的"常值模式"，所以零特征值的个数就是孤岛数。**

### 谱聚类：沿着最细的地方切开

思路可以这样理解：**把图当成一块果冻，Fiedler 向量告诉你哪儿最细，一刀下去就是最自然的分界。**

算法四步：

1. 算 Laplacian L。
2. 求 L 的 k 个最小特征向量（连通图要跳过第一个全 1 的向量，那是"整体平移"，不含分割信息）。
3. 把每个节点的这 k 个特征向量值**当成它的新坐标**。
4. 在这些新坐标上跑 k-means。

为什么这样就行？因为 **L 的特征向量编码的是图上"最平滑"的那些函数**——所谓平滑，就是"相邻节点的值尽量接近"。连通得好的节点自然被压成相似的值；被瓶颈隔开的节点，平滑性一要求，就会被迫分成两拨。所以聚类根本不用做，它已经写在特征向量里了。

**和随机游走的关系**：归一化 Laplacian 与"图上随机游走"紧密相关。游走者的平稳分布正比于节点度（度高的地方他被引过去的机会更多）。而游走多久能"忘记起点"，取决于谱间隙——谱间隙大，混得快，图连通得好。

### 消息传递：每个节点开一次邻居会

这是 GNN 的核心操作。每个节点做三件事：**收邻居的消息 → 聚合 → 更新自己。**

\[
h_v^{k+1}=\mathrm{UPDATE}\Big(h_v^k,\ \mathrm{AGGREGATE}\big(\{h_u^k:u\in N(v)\}\big)\Big)
\]

最简版本里，聚合就是取平均，更新就是线性变换加激活：

\[
h_v^{k+1}=\sigma\Big(W\cdot \mathrm{mean}\big(\{h_u^k:u\in N(v)\}\big)\Big)
\]

而这一步其实是**伪装起来的矩阵乘法**。把所有节点的特征摞成矩阵 H，A 是邻接矩阵：

\[
H^{k+1}=\sigma\big(A_{norm}H^kW\big)
\]

（\(A_{norm}\) 是行归一化的邻接矩阵，每行加起来等于 1，等价于"取平均"。）

**层数的含义特别值得记：**

- 1 轮：每个节点看见**直接邻居**。
- 2 轮：看见**邻居的邻居**。
- K 轮：手里攥着**K 跳邻域**的全部信息。

所以"GNN 有几层"其实等价于"每个节点能看多远"。层数堆太多也有副作用——所有节点最后都收到几乎一样的信息，特征被磨平，这叫过平滑。

### 这些概念在 ML 里各干什么

| 概念 | ML 里的用途 |
|------|------------|
| 邻接矩阵 | GNN 的输入表示 |
| 图 Laplacian | 谱聚类、社区检测 |
| BFS/DFS | 知识图谱遍历、路径查找 |
| 度分布 | 节点重要性、特征工程 |
| 消息传递 | GNN 的层（GCN / GAT / GraphSAGE） |
| L 的特征值 | 社区检测、图划分 |
| 谱聚类 | 无监督地把节点分组 |
| PageRank | 节点重要性、网页排序 |

## 练习

1. **从零实现 PageRank。** 初始化成均匀分数。每轮更新 \(\text{score}(v)=(1-d)/n+d\sum_{u\to v}\text{score}(u)/\text{outdeg}(u)\)，取 d=0.85，跑到收敛（变化小于 1e-6），在一个小网页图上测试。
2. **谱聚类找社区。** 造两个明显分离的团（中间只连一条边），跑谱聚类，看它是否切对。再逐步加跨团的边，观察它什么时候开始"切不准"。
3. **实现 Dijkstra。** 在带权图上求最短路径，然后把所有边权设为 1，和 BFS 的结果对照。
4. **两层消息传递。** 用两个不同的权重矩阵连做两次消息传递，验证两轮之后每个节点确实掌握了二跳邻域的信息。
5. **分析真实图。** 用 Karate Club（34 节点、78 边）。算度分布、Laplacian 特征值，跑谱聚类，和公认的社区划分对比。

## 关键术语

| 术语 | 人们常说 | 实际含义 |
|------|---------|---------|
| 图 | "点跟线" | 用成对关系编码数据的结构 G=(V,E) |
| 邻接矩阵 | "连接表" | n×n 矩阵，A[i][j]=1 表示 i、j 相连 |
| 度 | "连得多不多" | 接到这个节点的边数 |
| Laplacian | "D 减 A" | L=D−A，它的特征值把图的结构全交代了 |
| Fiedler 值 | "代数连通度" | L 的最小非零特征值，衡量图的连通结实程度 |
| BFS | "一层层搜" | 先看所有邻居再看更深，能找最短路径 |
| DFS | "一条路走到底" | 钻进死胡同再回头 |
| 消息传递 | "节点跟邻居开会" | 每个节点聚合邻居信息再更新自己，GNN 的核心 |
| 谱聚类 | "用特征向量分组" | 拿 Laplacian 的特征向量当坐标去聚类 |
| 连通分量 | "单独的一块" | 内部任意两点互相可达的最大子图 |
