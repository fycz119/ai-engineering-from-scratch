# 凸优化

> 凸问题只有一个山谷。神经网络有几百万个。搞清这个差别很值钱。

**类型：** 构建
**语言：** Python
**先修知识：** 第1阶段，第04课（微积分 for ML）、第08课（优化）
**时间：** 约90分钟

## 学习目标

- 用定义、二阶导数、Hessian 三种方法检验一个函数是不是凸的
- 亲手实现牛顿法，看清它和梯度下降的"二次收敛"差在哪
- 用 Lagrange 乘子解带约束的优化，并读懂 KKT 条件在说什么
- 解释神经网络明明是非凸的，SGD 却仍能找到好解

## 问题

第08课教了梯度下降、动量、Adam。这些优化器在**任何**曲面上都能往下走，但什么也不保证。非凸地形上，梯度下降可能掉进一个糟糕的坑、卡在鞍点上、或者永远来回震荡。你仍然用它，因为神经网络本来就是非凸的，没有更好的替代。

但 ML 里有一大批问题是**凸**的：线性回归、逻辑回归、SVM、LASSO、岭回归。对这些问题，存在更强的东西——**带数学保证的优化**。

道理很简单：凸问题只有一个山谷。**不管从哪儿出发，只要一直往下走，最终都到同一个最低点。** 不用随机重启，不用精细调学习率，不用"试试看运气"。

理解凸性还能给你三样东西：第一，判断一个问题什么时候简单、什么时候困难；第二，对凸问题换更快的工具（牛顿法）；第三，看懂一串贯穿 ML 的概念——正则化其实是约束优化、SVM 的对偶、以及深度学习为什么违反了一堆"美好性质"却依然工作。

## 概念

### 凸集：没有凹陷，没有孔洞

一个集合 S 是凸的，意思是：**在里面随便挑两个点，连成线段，这根线不会跑出去。**

```text
凸集：矩形、三角形、直线/平面/整个 R^n、球、半空间 {x : a^T x <= b}、任意多个凸集的交集
非凸：甜甜圈（中间有洞）、两个不相交的圆并在一起、任何带凹坑或洞的东西
```

形式化写法：对任意 \(x,y\in S\) 和 \(t\in[0,1]\)，\(tx+(1-t)y\) 仍属于 S。

> 注：凸集的直觉就是"从内部看任何地方都不用绕"。这对优化很关键——可行域是凸的，约束就不会把可搜索区域切成碎块，搜索者不用在多个碎片之间跳来跳去。

### 凸函数：弦永远在函数上方

函数 \(f\) 是凸的，前提是它的定义域是凸集，且对任意 \(x,y\) 与 \(t\in[0,1]\)：

\[
f\big(tx+(1-t)y\big)\le tf(x)+(1-t)f(y)
\]

这句话的几何含义很直观：**在图上随便取两点，连一条直线（弦），这根弦一定落在函数曲线上方（或贴着）。**

也就是说，函数永远"往下凹"——像一个碗。

几个典型凸函数：\(x^2\)、\(|x|\)、\(e^x\)、\(\max(0,x)\)（ReLU，分段线性）、\(-\log x\)（x>0）、任何线性函数 \(a^Tx+b\)。

### 三个检验方法：从易到严

**检验一：二阶导数（一维）。** 若 \(f''(x)\ge 0\) 对所有 x 成立，则 f 凸。

- \(x^2\)：\(f''=2\ge 0\) → 凸
- \(x^3\)：\(f''=6x\)，x<0 时为负 → 不凸
- \(e^x\)：\(f''=e^x>0\) → 凸

**检验二：Hessian（多维）。** 若 Hessian 矩阵处处半正定（所有特征值 ≥ 0），则 f 凸。

**检验三：直接套定义。** 有些函数导数难算，那就老老实实验证那个不等式。

### 为什么这件事这么重要

凸优化最核心的一条定理：**对凸函数，每一个局部最小都是全局最小。**

翻成大白话：如果你蒙着眼在一个完美的碗里往下走，走到走不动为止，那你就到了碗底——**不可能有"另一个更深的坑"**。

由此带来的好处是一连串的：

- 不用随机重启（反正每个起点都到同一个地方）
- 不用设计复杂的学习率调度
- 可以写出收敛速度的证明
- 解是唯一的（除了整片平坦的区域）

### ML 里哪些是凸的，哪些不是

| 问题 | 凸？ | 原因 |
|------|-----|------|
| 线性回归（MSE） | 是 | 损失对权重是二次的 |
| 逻辑回归 | 是 | log-loss 对权重是凸的 |
| SVM（hinge） | 是 | 一串线性函数取最大值，仍是凸的 |
| LASSO（L1） | 是 | 凸函数相加还是凸的 |
| 岭回归（L2） | 是 | 二次加二次，还是凸的 |
| 神经网络 | 否 | 非线性激活造出了非凸地形 |
| k-means | 否 | 分配那一步是离散跳变 |
| 矩阵分解 | 否 | 未知量之间相乘 |

规律很清楚：**"线性模型 + 凸损失"永远是凸的；一旦加了隐藏层和非线性激活，凸性立刻破功。**

### Hessian：曲率的完整说明书

Hessian 是二阶偏导组成的矩阵：

\[
H_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}
\]

以 \(f=x^2+3xy+y^2\) 为例：

\[
H=\begin{bmatrix}2&3\\3&2\end{bmatrix}
\]

Hessian 告诉你的是**每个方向的弯曲程度和方向**：

- 特征值全为正 → 每个方向都向上弯 → 这是个碗（该点凸）
- 全为负 → 每个方向都向下弯 → 穹顶（局部最大）
- 有正有负 → 一个方向向上、一个方向向下 → 鞍点
- 有零特征值 → 那个方向是平的

而"函数凸"要求的是**在所有点上** Hessian 都半正定，不只是某一个点。

> 注：Hessian 就是"多维版的 f''"。一维里 \(f''\ge0\) 表示向上弯；多维里对应的说法就是"Hessian 半正定"。特征值的正负决定弯曲方向：全正像碗，全负像帽子，正负都有像马鞍。

### 牛顿法：看曲率决定步子

梯度下降只用一阶信息（往哪个方向下坡），牛顿法连二阶信息（坡有多弯）一起用。

它的做法是：在当前点附近用一个二次函数（抛物线/抛物面）去拟合原函数，然后**直接跳到这个二次近似的最低点**。

```text
牛顿法：x_new = x - H^{-1} * gradient
梯度下降：x_new = x - lr * gradient
```

区别一眼就看出来了：梯度下降乘的是一个标量学习率，牛顿法乘的是**逆 Hessian**——它按局部曲率自动决定该走多远、往哪个方向走。陡的地方自动小步，平的地方自动大步。

**优势**：
- 最小值附近**二次收敛**——误差每步被平方，精度位数翻倍（1e-3 → 1e-6 → 1e-12）。
- 不用调学习率。
- 对尺度不敏感（换个单位它照样走对）。

**劣势**：
- 存 Hessian 要 \(O(n^2)\) 内存，求逆要 \(O(n^3)\)。
- 百万权重的网络：Hessian 有 \(10^{12}\) 个元素，求逆要 \(10^{18}\) 量级操作——完全不可行。

所以纯牛顿法在深度学习里基本见不到，它属于"小规模凸问题"的精密工具。

### 约束优化：不是整片山，是围栏里的一座山

前面都是"在整个空间里找最低点"。现实里常有围栏：**成本要最低，但预算不能超；误差要最小，但模型复杂度有上限。**

于是问题变成：在允许的区域里找最低点。

### Lagrange 乘子：把围栏变成罚分

想法很巧妙：不硬性禁止越界，而是**越界就罚钱**，罚到你不敢越。

原问题：最小化 \(f(x)\)，满足 \(g(x)=0\)。引入一个新变量 \(\lambda\)，构造：

\[
\mathcal{L}(x,\lambda) = f(x) + \lambda g(x)
\]

然后对它求梯度置零：

```text
∂L/∂x = ∂f/∂x + λ ∂g/∂x = 0
∂L/∂λ = g(x) = 0        （这一条就是"必须满足约束"）
```

**几何直觉**：在约束下的最优点，\(f\) 的梯度必须与约束面 \(g\) 的梯度**平行**。

为什么？因为 \(f\) 的梯度是"最想往下走的方向"，\(g\) 的梯度是"垂直于围栏的方向"。如果这两个方向不平行，说明 \(f\) 的下降方向还有一部分**沿着围栏**——那你就可以贴着围栏再往下滑一点，说明还没到最优点。只有当你"想走的方向"被围栏的法向完全挡住时，才是真的走不动了。

看个例子：在直线 \(x+y=1\) 上找离原点最近的点。

```text
f = x² + y²，约束 g = x + y - 1 = 0

L = x² + y² + λ(x + y - 1)

∂L/∂x = 2x + λ = 0   → x = -λ/2
∂L/∂y = 2y + λ = 0   → y = -λ/2
∂L/∂λ = x + y - 1 = 0 → 2x = 1

解得 x = y = 0.5，λ = -1
```

直线 \(x+y=1\) 上离原点最近的点确实是 (0.5, 0.5)，答案对上了。

### KKT 条件：围栏可以"松"，也可以"紧"

Lagrange 只能处理等式约束（必须精确站在围栏上）。KKT 把它推广到不等式约束（可以站在围栏里面，也可以贴着围栏）：

最小化 \(f(x)\)，满足 \(g_i(x)\le 0\)。

```text
KKT（最优的必要条件）：
1. 平稳性：   ∂f/∂x + Σ λ_i ∂g_i/∂x = 0
2. 原始可行： g_i(x) <= 0            （解确实在围栏内）
3. 对偶可行： λ_i >= 0               （罚分方向不能反）
4. 互补松弛： λ_i * g_i(x) = 0
```

**互补松弛是关键中的关键，它像一个开关：**

- 如果约束**紧**（\(g_i=0\)，解正好贴在围栏上），那 \(\lambda_i\) 可以大于 0，围栏在起作用。
- 如果约束**松**（\(g_i<0\)，解在围栏里面），那就必须 \(\lambda_i=0\)，这条约束等于不存在。

两者不可能同时非零——**要么围栏推着你，要么围栏根本没人碰。**

这直接解释了 SVM 最著名的性质。SVM 里每条约束对应一个数据点：

- **支持向量**：正好贴在间隔边界上的点，约束是紧的，\(\lambda>0\)，它们决定了决策边界。
- **其他所有点**：都在边界之外远远待着，约束是松的，\(\lambda=0\)，它们对边界毫无影响。

所以"支持向量机"这个名字不是比喻——**真的只有少数几个点"支撑"着那条边界。** 你把其他样本全删掉，模型一个字都不会变。

> 注：把互补松弛记成一个开关：约束要么起作用（解贴着边界），要么乘子归零（约束完全不影响解）。这就是 SVM 稀疏性的来源。

### 正则化：被伪装起来的约束优化

很多人以为 L1/L2 正则化是"防止过拟合的小技巧"。它其实是一个**约束优化问题换了件衣服**。

**L2（Ridge）：**

```text
min Loss(w)   满足  ||w||² <= t
等价的无约束形式：min Loss(w) + λ ||w||²
```

约束 \(||w||^2\le t\) 是一个**球**（二维里是圆）。解就是"损失的等高线第一次碰到这个球"的位置。因为球面光滑，触点可以落在任何地方，所以权重被整体缩小，但很少恰好等于零。

**L1（LASSO）：**

```text
min Loss(w)   满足  ||w||_1 <= t
等价的无约束形式：min Loss(w) + λ ||w||_1
```

约束 \(||w||_1\le t\) 是一个**菱形**（二维里是旋转 45° 的正方形）。

| 属性 | L2 约束（圆） | L1 约束（菱形） |
|------|--------------|----------------|
| 约束形状 | 圆/球 | 菱形（二维是旋转过的方块） |
| 等高线碰在哪 | 光滑边界上的任意点 | 尖角（正好落在坐标轴上） |
| 解的样子 | 权重都变小，但没有零 | 部分权重**恰好为零**（稀疏） |
| 效果 | 收缩 | 特征选择 |

为什么菱形会造成稀疏？想象往一个菱形上"顶"一张椭圆形的等高线。菱形的**尖角正好戳在坐标轴上**，而等高线越往外扩，越容易先碰到尖角——一旦碰到尖角，就意味着某个坐标恰好是 0。

所以 L1 不只是"把权重压小"，它是**直接把某些特征踢出模型**。这就是 LASSO 天生能做特征选择的原因。

### 对偶：每个问题都有一个"镜像版"

每个带约束的优化问题（原问题）都有一个伴随的问题（对偶问题）。对凸问题，两者的最优值相等——这叫**强对偶**。

```text
原问题：  min f(x)   s.t. g(x) <= 0
Lagrangian：L(x, λ) = f(x) + λ g(x)
对偶函数：d(λ) = min_x L(x, λ)
对偶问题：max d(λ)   s.t. λ >= 0
```

对偶为什么值得学：

- **有时候对偶比原问题好解**（约束变简单了）。
- **SVM 在对偶形式下求解**，而对偶形式只依赖数据点之间的**点积**——这就是核技巧的入口。
- **对偶给出原问题最优值的下界**，可以用来检验你的解离最优还有多远。

SVM 的对偶长这样：

```text
原问题：找 w, b 最大化间隔 2/||w||，满足 y_i(w^T x_i + b) >= 1

对偶：max  Σ α_i - 0.5 Σ_ij α_i α_j y_i y_j (x_i^T x_j)
      s.t. α_i >= 0,  Σ α_i y_i = 0
```

看最后那个式子：**数据只以 \(x_i^Tx_j\) 这个点积的形式出现。** 于是你可以直接把点积换成核函数 \(K(x_i,x_j)\)，模型瞬间就能处理非线性边界——这就是"核技巧"的全部秘密，一个替换动作。

### 深度学习凭什么在非凸上也能成？

神经网络的损失面是非凸的，而且是极度非凸。按教科书标准，优化应该彻底失败。可 SGD 就是稳定地找到好解。原因有几条：

**第一，绝大多数局部最小其实都够用。** 在极高维空间里，梯度为零的"临界点"绝大多数是**鞍点**，不是局部最小。真正存在的局部最小，损失值往往和全局最小差不多。在百万维参数空间里恰好掉进一个"糟糕的局部最小"，概率低到不用考虑。

**第二，真正的障碍是鞍点，不是局部最小。** n 个参数的函数，在临界点上"所有 n 个方向都向上弯"的概率大约只有 \(2^{-n}\)——几乎为零。所以随机撒一个点，它基本都落在鞍点附近。而 SGD 的噪声正好能把优化器从鞍点的平坦区推出去。

**第三，过参数化会把地形磨平。** 参数比样本多的网络，损失面更平滑、更连通，坏坑更少。"网络越宽越不容易卡住"这件事反直觉，但经验上一直成立。

**第四，小批量的噪声是一种隐式正则。** 它让你不容易停在尖锐的最小值上。而尖锐最小值通常对应过拟合，平坦最小值泛化更好——噪声相当于把优化过程往平坦区域偏。

### 二阶方法的工程化版本

纯牛顿法在大模型上用不了，但"用上一些二阶信息"仍然可行，办法是各种近似：

- **L-BFGS**：不存完整 Hessian，只存最近 m 步的梯度差，用它近似逆 Hessian。内存从 \(O(n^2)\) 降到 \(O(mn)\)。适合一万参数左右的问题——经典 ML 常用，深度学习不用。
- **自然梯度**：用 Fisher 信息矩阵（对数似然的期望 Hessian）替代普通 Hessian，考虑的是概率分布的几何而不是参数空间的几何。K-FAC 进一步把 Fisher 近似成 Kronecker 积，让神经网络也能算。
- **Hessian-free**：不显式构造 H，而是用共轭梯度直接解 \(Hx=g\)。它只需要"Hessian 乘一个向量"，而这个乘积用自动微分就能 \(O(n)\) 算出来。
- **对角近似**：Adam 的二阶矩其实就是 Hessian 对角的一种粗略近似；AdaHessian 用 Hutchinson 估计器去逼近真实的 Hessian 对角。

| 方法 | 内存 | 每步成本 | 什么时候用 |
|------|------|---------|-----------|
| 梯度下降 | O(n) | O(n) | 基线、大模型 |
| 牛顿法 | O(n²) | O(n³) | 小规模凸问题 |
| L-BFGS | O(mn) | O(mn) | 中等规模凸问题 |
| Adam | O(n) | O(n) | 深度学习的默认选择 |
| K-FAC | O(n) | 每层 O(n) | 研究、大 batch 训练 |

## 练习

1. **凸性画廊。** 用检查器分别测 \(x^4\)、\(\sin x\)、\(x^2+y^2\)、\(xy\)、\(\max(x,0)\)，逐个解释结果。
2. **牛顿 vs 梯度下降。** 从 (10,10) 出发优化 \(f=50x^2+y^2\)，两种方法各要多少步才能把 loss 压到 1e-10 以下？再逐步加大条件数（Hessian 最大/最小特征值之比），看梯度下降怎么越来越慢。
3. **Lagrange 的几何。** 最小化 \(f=(x-3)^2+(y-3)^2\)，满足 \(x+2y=4\)。解出来之后，验证在最优点上 f 的梯度确实与 g 的梯度平行。
4. **正则化即约束。** 实现带约束的优化：min \((x-3)^2+(y-2)^2\)，满足 \(|x|+|y|\le 1\)。观察解里至少有一个坐标是 0——这就是菱形的稀疏性。
5. **Hessian 特征值。** 算 Rosenbrock 函数在 (1,1) 和 (-1,1) 两处的 Hessian 特征值，对比"在最小值处"和"远离最小值处"的曲率差异。

## 关键术语

| 术语 | 含义 |
|------|------|
| 凸集 | 集合中任意两点连成的线段仍完整落在集合内 |
| 凸函数 | 图上任意两点连的弦位于曲线上方；等价地说 Hessian 处处半正定 |
| 局部最小 | 比周围所有点都低，但未必是全场最低；凸函数里它一定是全局最小 |
| 全局最小 | 整个定义域上的最低点 |
| Hessian 矩阵 | 所有二阶偏导组成的矩阵，编码曲率信息 |
| 半正定 | 特征值全非负，"二阶导数 ≥ 0"在多维里的对应说法 |
| 条件数 | Hessian 最大与最小特征值之比，越大山谷越细长，梯度下降越慢 |
| 牛顿法 | 用逆 Hessian 定步长和方向，最小值附近二次收敛 |
| Lagrange 乘子 | 引入新变量把约束问题变无约束的那个技巧 |
| KKT 条件 | 不等式约束下最优的必要条件，是 Lagrange 乘子的推广 |
| 互补松弛 | 在最优点，约束要么紧（乘子>0），要么松（乘子=0） |
| 对偶 | 每个约束问题都有伴随的对偶问题；凸问题下两者最优值相同 |
| 强对偶 | 原问题与对偶问题最优值相等；满足 Slater 条件的凸问题一定成立 |
| L-BFGS | 只存最近 m 步梯度差来近似 Hessian 的二阶方法 |
| 鞍点 | 梯度为零，但在某些方向是最小、另一些方向是最大 |
| 过参数化 | 参数比样本还多，会把损失面磨平、减少坏局部最小 |
