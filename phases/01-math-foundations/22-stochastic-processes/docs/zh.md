# 随机过程

> 随机性也有结构。随机游走、马尔可夫链、扩散模型，用的都是这一套。

**类型：** 学习
**语言：** Python
**先修知识：** 第1阶段，第06-07课（概率、贝叶斯）
**时间：** 约75分钟

## 学习目标

- 模拟一维/二维随机游走，验证"距离只按 \(\sqrt{n}\) 增长"这条标度律
- 搭一个马尔可夫链模拟器，用特征分解算出平稳分布
- 实现 Metropolis-Hastings 和 Langevin 动力学，从指定分布里取样本
- 把前向扩散过程和布朗运动接上，讲清反向过程为什么能生成数据

## 问题

很多 AI 系统里的随机性**不是一次性的，而是随时间一步步演化的**——每一步都依赖上一步。

语言模型逐 token 生成：给一个上下文，算出下一个 token 的分布，采一个，再接上。这就是一个随机过程。

扩散模型一步步往图上加噪声，直到变成纯雪花屏；再一步步去噪，直到冒出张新图。前向是一条马尔可夫链，反向是一条"学出来的、倒着跑的"马尔可夫链。

RL 智能体在环境里行动，每次动作按某个概率把你推进新状态。整个过程叫马尔可夫决策过程。

MCMC 采样——贝叶斯推断的支柱——干的事就是造一条马尔可夫链，让它的平稳分布恰好等于你想要的后验。

这四件事其实都建立在四个基础想法上：**随机游走**（最简单的随机过程）、**马尔可夫链**（带转移矩阵的结构化随机）、**Langevin 动力学**（带噪声的梯度下降）、**Metropolis-Hastings**（从任意分布取样本）。

## 概念

### 随机游走：醉汉的一小步

从 0 开始。每一步抛一枚公平硬币：正面往右走一格（+1），反面往左走一格（−1）。

走 n 步之后，位置就是 n 个 ±1 的和。

**期望位置仍然是 0**——每一步都是公平的，没有任何偏向，平均下来当然不动。但**离起点的距离却在增长**，而且按 \(\sqrt{n}\) 增长。

```text
第 0 步：位置 0
第 1 步：+1 或 -1
第 100 步：离原点大约 10（= sqrt(100)）
第 10000 步：离原点大约 100（= sqrt(10000)）
```

这就是那个反直觉的地方：**规则完全公平、没有任何推力，但走着走着就飘远了。** 走得越久，飘得越远，只不过飘得不快——步数翻 100 倍，距离只翻 10 倍。

二维版就是把"左右"扩成"上下左右"，\(\sqrt{n}\) 的标度依然成立，走出来的轨迹像一条毛茸茸的、自相似的折线（分形）。

**为什么恰好是 \(\sqrt{n}\)？** 因为每一步的方差是 1，n 步互相独立，方差线性累加：\(\mathrm{Var}(S_n)=n\)，于是标准差是 \(\sqrt{n}\)。再由中心极限定理，\(S_n/\sqrt{n}\) 会收敛到标准正态。

这条标度律在 ML 里到处冒头：

- SGD 的梯度噪声按 \(1/\sqrt{\text{batch size}}\) 缩小——四倍批量只换来一半的噪声。
- 嵌入维度越大，随机初始化的向量长度按 \(\sqrt{d}\) 增长。

**只要是一堆独立随机量相加，平方根就自动出现。** 它是"独立相加"这件事的签名。

**和布朗运动的联系**：把随机游走的步长缩到 \(1/\sqrt{n}\)、单位时间里走 n 步，让 n 趋于无穷，它就会收敛到一个连续时间过程——布朗运动 \(B(t)\)，满足 \(B(t)\sim N(0,t)\)。

布朗运动是扩散的数学基础：水里花粉的抖动、股价的漂移、以及扩散模型里的加噪过程，全是它。

**赌徒破产**：从位置 k 出发，两端 0 和 N 是悬崖，先碰到哪边？公平游走下，先碰到 N 的概率恰好是 \(k/N\)。答案干净得惊人，背后是鞅论——公平随机游走是鞅，"未来的期望值 = 现在的值"，所以任何"位置 × 概率"的加权平均都不随时间改变。

> 注：\(\sqrt{n}\) 的来源就一句话：**独立 + 方差可加。** 每步方差 1，n 步就是 n，标准差 \(\sqrt{n}\)。这也直接解释了为什么"平均 n 个独立噪声"能把误差压到 \(1/\sqrt{n}\)——方差除以 n，标准差除以 \(\sqrt{n}\)。

### 马尔可夫链：健忘的机器

系统按固定的概率在状态之间跳。它有个关键性格：

\[
P(X_{t+1}=j\mid X_t=i,X_{t-1},\dots)=P(X_{t+1}=j\mid X_t=i)
\]

**下一步是什么，只看现在在哪儿，不看你是怎么走到这儿的。**

打个比方：你在地铁 2 号线某站，下一站去哪，只取决于当前这一站，跟你从哪条线换乘过来完全无关。历史被"忘掉"了。

整个动力系统就压成一张**转移矩阵** P：

\[
P_{ij}=\text{从状态 i 跳到 j 的概率}
\]

每行加起来必须是 1——从任何状态出发，你总得去某个地方。

举个天气的例：

```text
状态：晴(0)、雨(1)、阴(2)

P = [[0.7, 0.1, 0.2],    # 今天晴：明天 70% 晴、10% 雨、20% 阴
     [0.3, 0.4, 0.3],    # 今天雨：明天 30% 晴、40% 雨、30% 阴
     [0.4, 0.2, 0.4]]    # 今天阴：明天 40% 晴、20% 雨、40% 阴
```

**平稳分布**：不管今天是什么天气，预报着预报着，分布会稳定下来，满足 \(\pi P=\pi\)。它是 P 的左特征向量（对应特征值 1）。

上面这条天气链的平稳分布是 [0.55, 0.18, 0.27]——**长期来看，55% 的日子是晴天，而且这个比例跟起点无关。**

两种算法：

1. **幂法**：拿任意初始分布反复乘 P，自然收敛。
2. **特征值法**：求 \(P^T\) 对应于特征值 1 的特征向量。

**收敛需要两个条件：**

- **不可约**：任何状态都能（经过若干步）到达任何其他状态。没有进得去出不来的死胡同。
- **非周期**：链不能严格按某个周期原地打转。比如"必定 A→B→A→B"，它就不收敛到单一分布。

ML 里遇到的链基本都满足这两条。

**吸收态**：一旦进去就出不来（\(P_{ii}=1\)）。这类"吸收马尔可夫链"专门用来建模"有终点的过程"：结束了的游戏、流失了的客户、以及吐出 EOS token 的文本序列。

**混合时间**：链要跑多少步才"闻不出起点"？严格定义是全变分距离小于某个阈值所需的步数。控制它的是 P 的**谱间隙**（1 减去第二大的特征值）——间隙越大，混合越快。

### 语言模型其实就是马尔可夫链的近亲

LLM 逐 token 生成，非常像马尔可夫过程：给定当前上下文，模型给出下一个 token 的分布。

严格说有个技术细节：如果把"状态"定义为**整段历史**，那它仍然完美满足马尔可夫性质——只是状态空间大到没法枚举。实践中模型用有限的上下文窗口来近似它。

温度、top-k、top-p 这三样东西，都是在**改转移概率**：

```text
P(token_i) = exp(logit_i / T) / Σ exp(logit_j / T)

T = 1   标准
T < 1   更尖锐、更确定
T > 1   更平坦、更随机
T -> 0  退化成贪心
```

top-k 把候选截到最高的 k 个；top-p 截到累计概率刚超过 p 的最小集合。**它们改的都是"从当前状态能跳到哪些状态、各有多大机会"**，也就是 P 的那一行。

### 布朗运动：连续版的随机游走

它是随机游走在"每步越走越小、步数越走越多"的极限下得到的连续过程。位置 \(B(t)\) 有三条性质：

1. \(B(0)=0\)
2. \(B(t)-B(s)\sim N(0,t-s)\)，当 \(t>s\)
3. 不重叠的区间上的增量互相独立

布朗运动有一件很诡异的事：**它处处连续，但处处不可微。** 因为不管你把镜头推到多近，它都还在抖动。它的路径在平面上的分形维数是 2。

离散模拟：

\[
B(t+dt)=B(t)+\sqrt{dt}\,z,\qquad z\sim N(0,1)
\]

注意那个 \(\sqrt{dt}\)，不是 dt。这正是"随机游走 → 布朗运动"要满足的标度关系，来源仍然是方差可加 + 中心极限定理。

### Langevin 动力学：被随机推着的下山球

梯度下降找函数的最小值。Langevin 动力学**采样**一个正比于 \(\exp(-U(x)/T)\) 的分布，其中 U 是能量函数，T 是温度。

\[
x_{t+1}=x_t-dt\cdot\nabla U(x_t)+\sqrt{2T\,dt}\cdot z_t
\]

更新里有两只手在推你：

1. **梯度力** \(-dt\cdot\nabla U\)：把你往低处拉，跟梯度下降一模一样。
2. **随机力** \(\sqrt{2T\,dt}\cdot z\)：随机朝某个方向推一把。

温度 T 决定谁说话更响：

- **T=0**：随机力归零，退化成纯梯度下降，只会滚到最近的坑底。
- **高温**：梯度力被淹没，几乎变成随机游走，到处乱窜。
- **合适的温度**：既会往低处走，又不会被某个坑困住——于是它会在低能量区域待得久、在高能量区域待得短，**停留时间的比例正好就是目标分布**。

这就是"用一条带噪声的下山路径，去采样整个地形"的核心思想。

### 扩散模型：把照片泡进噪声，再擦出来

前向过程是这么一条马尔可夫链：

```text
x_t = sqrt(alpha_t) * x_{t-1} + sqrt(1 - alpha_t) * noise
```

每一步都把"上一步的画面"和"纯噪声"按比例混一混。步数够多以后，\(x_T\) 就是纯高斯噪声——图像的信息被彻底泡散了。

**反向过程——从噪声走回数据——同样是一条马尔可夫链**，只不过每一步的转移概率是神经网络学出来的。网络学的任务是：**预测这一步被加进去的噪声是什么，然后把它减掉。**

所以"生成一张图"这件事，说到底就是：从纯噪声出发，沿着一条学到的马尔可夫链走几百步，每一步都甩掉一点噪声。

### MCMC：造一条"终点就是你想要的那个分布"的链

有时候你想从 \(p(x)\) 采样，能算出它的值（哪怕差一个常数），但没法直接抽。

**Metropolis-Hastings** 的解法是造一条链，让它的平稳分布恰好是 \(p(x)\)：

1. 从位置 x 出发。
2. 按提案分布 \(Q(x'|x)\) 提议一个新位置 \(x'\)。
3. 算接受率 \(\alpha=p(x')Q(x|x')\big/\big[p(x)Q(x'|x)\big]\)。
4. 以 \(\min(1,\alpha)\) 的概率接受 \(x'\)，否则**留在原地**（注意：留在原地也算一步）。
5. 重复。

如果提案是对称的（比如 \(Q(x'|x)=Q(x|x')\) 都是中心在 x 的高斯），接受率就简化成 \(p(x')/p(x)\)——**只需要两个概率的比值，归一化常数直接约掉了。** 这一个细节，就是 MCMC 能处理贝叶斯后验的全部秘密：你根本算不出那个常数，但你不需要它。

**为什么这样能收敛？** 因为这条接受规则保证了**细致平衡**：从 x 跳到 x' 的概率质量，正好等于从 x' 跳到 x 的概率质量。两边一平衡，整体分布不再变化，于是 \(p(x)\) 成了链的平稳分布。跑够久，样本就来自 \(p(x)\) 了。

**实战四条经验：**

- **Burn-in（预热）**：前若干步还没进入平稳状态，扔掉。
- **Thinning（抽稀）**：相邻样本高度相关，每隔 k 个取一个。
- **多链**：从不同起点跑几条链，如果最后都收敛到同一个分布，那就是收敛的强证据。
- **接受率**：d 维高斯提案下，理论最优接受率约为 23%（Roberts & Rosenthal 2001）。太高说明步子太小、链几乎不动；太低说明步子太大、全被拒绝。

## 练习

1. **跑 1000 条长度为 10000 步的随机游走。** 画最终位置的分布，验证它近似高斯、均值 0、标准差 \(\sqrt{10000}=100\)。
2. **用马尔可夫链写个文本生成器。** 在小语料上统计"每个词后面接什么词"的转移频率，建出转移矩阵，再采样生成新句子。
3. **实现模拟退火**（基于 MH）。从高温（几乎什么都接受）慢慢降温（逐渐只接受变好的），用它在一个有很多局部最小的函数上找全局最小。
4. **比较不同温度下的 Langevin。** 在双阱势 \(U=(x^2-1)^2\) 上采样。低温时样本全挤在一个阱里；高温时在两个阱之间来回跑。找出"开始能在两阱间混合"的临界温度。
5. **实现前向扩散。** 从一个一维信号（比如正弦）出发，用线性噪声调度走 100 步，看着它退化成纯噪声。然后实现一个简单的去噪器，把反向过程跑一遍。

## 关键术语

| 术语 | 人们常说 | 实际含义 |
|------|---------|---------|
| 随机游走 | "抛硬币挪步" | 每一步位置按随机增量变化的过程 |
| 马尔可夫性质 | "健忘" | 未来只依赖当前状态，与历史无关 |
| 转移矩阵 | "概率表" | P[i][j] = 从状态 i 跳到 j 的概率 |
| 平稳分布 | "长期平均" | 满足 πP=π 的分布，链达到平衡后的样子 |
| 布朗运动 | "随机抖动" | 随机游走的连续时间极限，B(t)~N(0,t) |
| Langevin 动力学 | "带噪声的梯度下降" | 确定性梯度 + 随机扰动组合起来的更新规则 |
| MCMC | "走向目标的链" | 构造一条平稳分布恰好是目标的马尔可夫链 |
| Metropolis-Hastings | "提案-接受/拒绝" | 用接受率保证收敛的 MCMC 算法 |
| 温度 | "随机性旋钮" | 控制探索与利用之间权重的参数 |
| 扩散过程 | "噪声进，噪声出" | 前向逐步加噪，反向逐步去噪，从而生成数据 |

## 延伸阅读

- Ho, Jain, Abbeel (2020) — "Denoising Diffusion Probabilistic Models"，DDPM，推导前向/反向马尔可夫链
- Song & Ermon (2019) — "Generative Modeling by Estimating Gradients"，基于分数的 Langevin 采样
- Roberts & Rosenthal (2004) — "General state space Markov chains and MCMC"
- Norris (1997) — "Markov Chains"，标准教材
- Welling & Teh (2011) — "Bayesian Learning via SGLD"，用 SGD + Langevin 做可扩展贝叶斯推断
- DDPM 的前向马尔可夫链是 \(q(x_t|x_{t-1})=N(x_t;\sqrt{1-\beta_t}x_{t-1},\beta_t I)\)，T 步后 \(x_T\approx N(0,I)\)；反向由网络预测噪声 \(p_\theta(x_{t-1}|x_t)=N(x_{t-1};\mu_\theta(x_t,t),\sigma_t^2 I)\)。生成的每一步，都是这条学到的马尔可夫链走一步
- SGLD 把小批量梯度下降和 Langevin 噪声结合起来：用随机梯度估计梯度，再按温度加校准过的噪声；学习率衰减时，过程从"优化"平滑过渡到"采样"，顺手得到近似贝叶斯后验样本
