# 范数与距离

> 你的距离函数定义了“相似”意味着什么。选错，下游一切都会坏掉。

**类型：** 构建
**语言：** Python

## 学习目标

- 从零实现 L1、L2、余弦、Mahalanobis、Jaccard 和编辑距离
- 为给定的 ML 任务选择合适的距离度量，并解释为什么其他方案会失败
- 把 L1/L2 范数与 LASSO/Ridge 正则化及其几何约束区域联系起来
- 证明同一份数据在不同度量下会产生不同的最近邻

## 问题

你有两个向量。它们可能是词嵌入、用户画像或像素数组。你需要知道：它们有多接近？

答案完全取决于你选了哪个距离函数。两个数据点在一个度量下是最近邻，在另一个度量下可能相距甚远。你的 KNN 分类器、推荐引擎、向量数据库、聚类算法、损失函数——全都依赖这个选择。选错，模型就会优化错目标。

没有通用的“最佳距离”。L2 适合空间数据，余弦相似度统治 NLP，Jaccard 处理集合，编辑距离处理字符串，Mahalanobis 考虑相关性，Wasserstein 移动概率质量。每一种都编码了不同的“相似”假设。

本课从零构建所有主要距离函数，说明每种何时是正确工具，并演示同一份数据在不同度量下如何产生完全不同的最近邻。

## 概念

### 范数：测量向量大小

范数衡量向量的“大小”。任意两个向量之间的距离都可以写成它们差的范数：d(a,b) = ||a - b||。所以理解范数就是理解距离。

> 注：范数不是随便一个“长度函数”。它必须满足三条公理：非负、绝对齐次（||cx|| = |c| ||x||）、三角不等式。很多初学者把“平方和开根”当作范数的定义，其实那是 L2 范数，只是范数家族的一员。

### L1 范数（曼哈顿距离）

L1 范数对所有分量取绝对值后求和。

```
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

叫曼哈顿距离，是因为它像在只能沿坐标轴走的城市网格上量距离，不能斜穿。

```
A = (1, 1), B = (4, 5)
L1 = |4-1| + |5-1| = 3 + 4 = 7
```

何时用 L1：
- 高维稀疏数据（文本特征、one-hot 编码）
- 需要对异常值鲁棒（单个巨大差异不会主导）
- 特征选择问题（L1 正则化促进稀疏）

与 L1 正则化（Lasso）的联系：在损失函数上加 ||w||_1 惩罚权重绝对值之和，把小权重推到恰好为零，自动完成特征选择。L1 的约束区域是菱形，角点落在坐标轴上（某些权重为零）。

与损失函数的联系：MAE 是预测与目标之间 L1 距离的平均值，线性惩罚，比 MSE 更抗异常值。

> 注：L1 对异常值鲁棒，是因为平方会把大误差放大（10 的平方是 100），而绝对值只是 10。所以 MSE 会被一个离群点带偏，MAE 不会。

### L2 范数（欧几里得距离）

L2 范数是直线距离：分量平方和的平方根。

```
||x||_2 = sqrt(x_1^2 + ... + x_n^2)
```

几何课学的毕达哥拉斯定理推广到 n 维。

```
A = (1, 1), B = (4, 5)
L2 = sqrt((4-1)^2 + (5-1)^2) = sqrt(9+16) = 5.0
```

何时用 L2：
- 低到中维的连续数据
- 特征尺度可比时
- 物理距离（空间数据、传感器读数）
- 像素级图像相似度

与 L2 正则化（Ridge）的联系：加 ||w||_2^2 惩罚大权重。不像 L1，它不把权重推到零，而是按比例把所有权重向零收缩。L2 的约束区域是圆/球，没有角点，权重变小但很少恰好为零。

与损失函数的联系：MSE 是 L2 距离的平方的平均值，平方对大误差惩罚更重。

```
MAE (L1 损失): |y - y_hat|        线性惩罚，抗异常值
MSE (L2 损失): (y - y_hat)^2      二次惩罚，对异常值敏感
```

### Lp 范数：通用家族

L1 和 L2 是 Lp 范数的特例：

```
||x||_p = (|x_1|^p + ... + |x_n|^p)^(1/p)
```

不同 p 产生不同形状的“单位球”（到原点距离为 1 的点集）：

```
p=1: 菱形（角点在坐标轴）
p=2: 圆/球（通常的圆球）
p=3: 超椭圆（圆角方块）
p=inf: 方/超立方体（沿坐标轴的平边）
```

> 注：p 越大，越强调最大分量；p 越小，越把“能量”分散到更多分量。p=0（严格说不是范数）对应稀疏性计数。

### L-infinity 范数（切比雪夫距离）

p 趋于无穷时，Lp 范数收敛到最大绝对分量。

```
||x||_inf = max(|x_1|, ..., |x_n|)
```

两点距离由它们差异最大的那个维度决定，其他维度全部忽略。

```
A=(1,1), B=(4,5)
L-inf = max(|4-1|, |5-1|) = max(3,4) = 4
```

何时用 L-infinity：
- 任意单维度的最坏偏差重要时
- 棋盘（国际象棋王一步走 L-infinity：任意方向 1 步代价为 1）
- 制造公差（每维度都必须在规格内）

### 余弦相似度与余弦距离

余弦相似度测量两个向量的夹角，忽略大小。

```
cos_sim(a,b) = (a·b) / (||a||_2 * ||b||_2)
```

范围 -1（反向）到 +1（同向），垂直向量为 0。余弦距离 = 1 - 余弦相似度，范围 0 到 2。

```
a=(1,0), b=(1,1)
cos_sim = (1*1+0*1)/(1*sqrt(2)) = 1/sqrt(2)=0.707
cos_dist = 1-0.707 = 0.293
```

为什么余弦在 NLP/嵌入中占统治地位：文本中文档长度不应影响相似度。两篇都关于猫、但一篇是另一篇两倍长的文档，仍应“相似”。余弦忽略大小（长度），只关心方向。词分布相同但长度不同的两篇文档指向同一方向，余弦相似度为 1.0。

何时用余弦相似度：
- 文本相似度（TF-IDF、词嵌入、句嵌入）
- 大小是噪声、方向是信号的领域
- 推荐系统（用户偏好向量）
- 嵌入检索（向量数据库几乎都用余弦或点积）

> 注：余弦相似度 = 把两个向量都单位化后再取点积。它把“方向”和“长度”解耦，这在文本/嵌入里非常关键，因为长度往往只是文档长短，不代表语义强度。

### 点积相似度 vs 余弦相似度

```
a·b = a_1 b_1 + ... + a_n b_n = ||a|| ||b|| cos(angle)
```

余弦相似度是点积除以两个模长。当两个向量已单位化（模长=1）时，点积与余弦相似度完全相同。

何时不同：点积包含大小信息。模长更大的向量得到更高分数。这在某些检索系统里有意义，大小可作为隐式质量/重要性信号。

```
a=(3,0), b=(1,0), c=(0,1)
dot(a,b)=3, dot(a,c)=0
cos(a,b)=1.0, cos(a,c)=0.0
```

实践中：
- 想要纯方向相似度用余弦
- 大小携带有意义信息用点积
- 许多向量数据库（Pinecone、Weaviate、Qdrant）可选
- 嵌入已 L2 归一化时，选择无关

### Mahalanobis 距离

欧氏距离把所有维度同等对待。但特征相关或尺度不同，L2 会误导。

Mahalanobis 距离考虑数据的协方差结构。

```
d_M(x,y) = sqrt((x-y)^T S^{-1} (x-y))
```

S 是数据协方差矩阵。

直觉：先去相关、归一化（白化），再在变换后的空间算 L2。若 S 是单位阵（不相关、单位方差），Mahalanobis 退化为欧氏。

```
身高与体重相关。
6'2" 180 磅的人不算异常。
5'0" 180 磅的人算异常。
欧氏可能说两者离均值等远；
Mahalanobis 因考虑身高-体重相关，正确识别后者为离群点。
```

何时用：
- 离群点检测（到均值 Mahalanobis 距离大的点是离群点）
- 特征尺度/相关性不同的分类
- 有足够数据估计可靠协方差矩阵时
- 制造质量控制（多变量过程监控）

> 注：Mahalanobis 的关键是对 S 求逆。如果特征完全共线，S 奇异不可逆——这就是为什么高维小样本时 Mahalanobis 不稳定，需要正则化或降维。

### Jaccard 相似度（用于集合）

Jaccard 衡量两个集合的重叠。

```
J(A,B) = |A ∩ B| / |A ∪ B|
```

范围 0（无重叠）到 1（相同）。Jaccard 距离 = 1 - Jaccard 相似度。

```
A={cat,dog,fish}, B={cat,bird,fish,snake}
交集={cat,fish} size=2
并集 size=5
Jaccard=2/5=0.4, 距离=0.6
```

何时用：
- 比较标签、类别、特征集合
- 基于词存在（非频率）的文档相似度
- 近重复检测（MinHash 近似 Jaccard）
- 二值特征向量（存在/缺失）
- 评估分割模型（IoU = Jaccard）

### 编辑距离（Levenshtein 距离）

编辑距离是把一个字符串变成另一个所需的最少单字符操作数，操作包括插入、删除、替换。

```
"kitten" -> "sitting"
kitten -> sitten (k->s)
sitten -> sittin (e->i)
sittin -> sitting (插入 g)
编辑距离 = 3
```

用动态规划计算：填表，(i,j) 表示 A 前 i 个字符与 B 前 j 个字符的编辑距离。

何时用：
- 拼写检查与纠错
- DNA 序列比对（带权操作）
- 模糊字符串匹配
- 脏数据去重

### KL 散度（不是距离，但常被当距离）

KL 散度衡量一个概率分布与另一个的差异。第09课已讲，但因人们把它当“距离”用，故列入。

```
D_KL(P || Q) = sum p(x) log(p(x)/q(x))
```

关键性质：KL 散度**不对称**：D_KL(P||Q) ≠ D_KL(Q||P)。因此它不满足距离度量的基本要求，也不满足三角不等式。它是散度，不是距离。

前向 KL（D_KL(P||Q)）“均值寻求”：Q 试图覆盖 P 的所有模态。
反向 KL（D_KL(Q||P)）“模态寻求”：Q 聚焦 P 的单个模态。

出现场景：
- VAE（ELBO 中的 KL 项把潜在分布推向先验）
- 知识蒸馏（学生匹配教师分布）
- RLHF（KL 惩罚让微调模型贴近基座模型）
- 策略梯度（约束策略更新）

> 注：不对称性意味着“用 Q 近似 P”和“用 P 近似 Q”是两件不同的事。VAE 用前向 KL，倾向于覆盖所有模式（可能模糊）；GAN 判别器相关用反向 KL，倾向于锐利但可能模式崩塌。

### Wasserstein 距离（Earth Mover's Distance）

Wasserstein 距离衡量把一个概率分布变成另一个所需的最少“功”。想象一堆土和一个坑：要搬多少土、搬多远？

```
W(P,Q) = inf_{transport plans gamma} E[d(x,y)]
```

对 1D 分布，简化为 CDF 差的绝对值积分：

```
W_1(P,Q) = integral |CDF_P(x) - CDF_Q(x)| dx
```

为什么重要：
- 是真正的度量（对称、满足三角不等式）
- 即使分布不重叠也能提供梯度（KL 散度会趋向无穷）
- 这一性质使它成为 Wasserstein GAN（WGAN）的核心，解决了原始 GAN 训练不稳定

```
分布无重叠：
P: [1,0,0,0,0]   Q: [0,0,0,0,1]
KL 散度: 无穷（log 0）
Wasserstein: 4（把所有质量搬 4 格）
Wasserstein 给出有意义的梯度，KL 不给。
```

何时用：
- GAN 训练（WGAN、WGAN-GP）
- 比较可能不重叠的分布
- 最优传输问题
- 图像检索（比较颜色直方图）

### 为什么不同任务需要不同距离

| 任务 | 最佳距离 | 原因 |
|------|---------|------|
| 文本相似度 | 余弦 | 大小是噪声，方向是语义 |
| 图像像素比较 | L2 | 空间关系重要，特征尺度可比 |
| 稀疏高维特征 | L1 | 鲁棒，不放大罕见大差异 |
| 集合重叠（标签、类别） | Jaccard | 数据天然是集合而非向量 |
| 字符串匹配 | 编辑距离 | 操作对应人类编辑直觉 |
| 离群点检测 | Mahalanobis | 考虑特征相关与尺度 |
| 比较分布 | KL 散度 | 衡量用 Q 代替 P 的信息损失 |
| GAN 训练 | Wasserstein | 分布不重叠时仍给梯度 |
| 嵌入（向量库） | 余弦或点积 | 嵌入把语义编码进方向 |
| 推荐 | 点积 | 大小可编码流行度/置信度 |
| DNA 序列 | 加权编辑距离 | 替换代价因核苷酸对而异 |
| 制造 QC | L-infinity | 任一维度的最坏偏差重要 |

### 与损失函数的联系

损失函数就是把距离函数应用到预测 vs 目标。

```
损失函数        使用的距离        行为
MSE             L2 的平方        重罚大误差
MAE             L1               所有误差等罚
Huber           大误差 L1、小误差 L2  兼顾鲁棒与零点平滑
交叉熵          KL 散度          分布不匹配
Hinge           max(0, margin-d) 仅罚低于间隔的
Triplet         L2（通常）       拉近正样本、推远负样本
Contrastive     L2               相似对靠近、不相似对超间隔
```

### 与正则化的联系

正则化在损失函数上加权重的范数惩罚。

```
L1 正则化 (Lasso): loss + lambda * ||w||_1
  -> 稀疏权重，部分恰好为零
  -> 自动特征选择
  -> 解有角点（零点不可导）

L2 正则化 (Ridge): loss + lambda * ||w||_2^2
  -> 小权重，全部向零收缩
  -> 无特征选择（很少恰好为零）
  -> 处处平滑

Elastic Net: loss + lambda_1||w||_1 + lambda_2||w||_2^2
  -> 结合 L1 稀疏与 L2 稳定
  -> 相关特征组被一起保留或丢弃
```

为什么 L1 产生稀疏而 L2 不：在 2D 权重空间画约束区域。L1 是菱形，L2 是圆。损失函数的等高线（椭圆）最可能先触到菱形的角点，那里某个权重为零；触到圆时是光滑点，两个权重都非零。

> 注：这就是“几何解释”。优化是在约束区域内找损失最小点，菱形的角点更容易被椭圆先碰到，所以 L1 自然把某些坐标压到 0。

### 最近邻搜索

每个距离函数都对应一个最近邻搜索问题：给定查询点，在数据集中找最近的点。

精确最近邻搜索对 n 个点、d 维数据每次查询 O(n*d)。大数据集太慢。

近似最近邻（ANN）用少量精度换巨大速度：

```
算法            方法                      使用者
KD 树           轴对齐空间划分            scikit-learn（低维）
Ball 树         嵌套超球                  scikit-learn（中维）
LSH             随机哈希投影              近重复检测
HNSW            分层可导航小世界图        FAISS, Qdrant, Weaviate
IVF             基于聚类的倒排文件        FAISS（十亿级）
乘积量化        压缩向量后在压缩空间搜索  FAISS（内存受限）
```

HNSW 是现代向量数据库的主导算法。它构建多层图，每节点连到近似最近邻。搜索从顶层（稀疏、长跳）开始，下降到底层（密集、短跳）。

## 使用

最常见的实际用法：在向量数据库中找相似项。

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)
sim_matrix = cosine_similarity_matrix(embeddings)
query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"Top 5 most similar to item 0: {top_k}")
```

调用 `model.encode(text)` 然后搜索向量数据库，底层就是这个。嵌入模型把文本映射为向量，向量库计算查询向量与所有存储向量的余弦相似度（或点积），用 ANN 算法避免遍历全部。

|------|---------|---------|
| 范数 | “向量大小” | 把向量映射到非负标量的函数，满足三角不等式、绝对齐次、仅零向量为零 |
| L1 范数 | “曼哈顿距离” | 分量绝对值之和，优化中产生稀疏，抗异常值 |
| L2 范数 | “欧氏距离” | 分量平方和的平方根，欧氏空间的直线距离 |
| Lp 范数 | “广义范数” | 分量 p 次幂之和的 p 次根，L1/L2 是特例 |
| L-infinity 范数 | “最大范数/切比雪夫距离” | 最大绝对分量，Lp 当 p→∞ 的极限 |
| 余弦相似度 | “向量夹角” | 点积除以两模长，范围 -1 到 1，忽略长度 |
| 余弦距离 | “1 减余弦相似度” | 把余弦相似度转为距离，范围 0 到 2 |
| 点积 | “未归一化的余弦” | 分量乘积之和，等于余弦相似度乘两模长 |
| Mahalanobis 距离 | “考虑相关的距离” | 在用数据协方差矩阵白化后的空间算 L2 |
| Jaccard 相似度 | “集合重叠” | 交集大小 / 并集大小，用于集合而非向量 |
| 编辑距离 | “Levenshtein 距离” | 把一个字符串变成另一个的最少插入/删除/替换 |
| KL 散度 | “分布间距离” | 不是对称距离；衡量用 Q 编码 P 的额外比特 |
| Wasserstein 距离 | “Earth Mover 距离” | 把一个分布变成另一个的最少搬运功，真正度量 |
| 近似最近邻 | “ANN 搜索” | HNSW/LSH/IVF 等算法，牺牲少量精度换巨大速度 |
| HNSW | “向量库算法” | 分层可导航小世界图，多层图加速近似最近邻 |
| L1 正则化 | “Lasso” | 损失加权重 L1 范数，权重变零（稀疏） |
| L2 正则化 | “Ridge/权重衰减” | 损失加权重 L2 范数平方，收缩但不稀疏 |
| Elastic Net | “L1+L2” | 结合 L1 稀疏与 L2 稳定，相关特征组一起保留/丢弃 |
